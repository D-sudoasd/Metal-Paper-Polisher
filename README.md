# 金属材料学论文精修与科学论证技能 v4

> 正式技能名：`metallic-materials-academic-editor`  
> 兼容仓库名：`materials-fracture-academic-polisher`

本项目用于金属材料、物理冶金、组织演化、相变与析出、变形机制、力学性能、疲劳与断裂、氢脆及环境损伤、高温与蠕变、增材制造、表征方法和计算材料学论文的中英文精修、逻辑诊断与全文论证重组。

v4 将项目从“断裂力学倾向的语言精修器”升级为“面向金属材料学的通用学术编辑技能”。仓库地址暂时保留旧名称以维持已有链接，技能元数据、文档标题和路由体系已经采用新名称。

## v4 的核心能力

1. **科学内容保护**：锁定数据、条件、术语、图表、引文范围和结论强度，不补写缺失事实或机制。
2. **句段精修**：重构句法、信息排序、比较条件、术语一致性、因果强度和段落节奏。
3. **论文类型路由**：根据核心科学问题切换机制、性能、变形、疲劳断裂、环境损伤、高温、制造、方法、计算或综述叙事。
4. **Results–Discussion 分工**：依据“结论离原始数据的距离”决定内容位置；Results 建立证据可直接支持的局部判断，Discussion 联合证据建立完整机制、检验替代解释并限定适用范围。
5. **性能类论文专用逻辑**：应用需求 → 性能瓶颈或权衡 → 设计动作 → 目标组织 → 定量性能 → 各项性能的独立来源 → 通常代价为何被抑制 → 适用边界。
6. **全文一致性检查**：题目、摘要、引言末段、结果、讨论和结论采用同一核心主张集合，并使每幅主图承担明确的证明任务。
7. **领域证据安全门**：针对同步辐射载荷分配、氢脆机制、疲劳驱动力、相变快照、峰宽解释、性能基准可比性等常见高风险推断设置专门核查。

## 推荐使用方式

### 单段或单节精修

```text
目标语言：英文
文本所属部分：讨论
论文类型：自动判定
任务类型：语言与逻辑精修
润色强度：中度逻辑与语言优化
架构干预：仅诊断
输出模式：完整模式

待处理文本：
[粘贴文本]
```

### 摘要重构

```text
文本所属部分：摘要
论文类型：性能设计
任务类型：摘要重构
润色强度：深度学术重写
架构干预：在原文证据链内重排
关键性能指标及测试条件：[填写]
比较基准：[填写]
```

### 全文 Results–Discussion 诊断

```text
文本所属部分：全文
任务类型：Results–Discussion 分工与全文架构审阅
允许跨段重排：是
证据审计：完整
输出模式：完整模式
```

## 默认行为

- 中文转英文：深度学术重写；默认允许段内重排，不允许跨段重排。
- 已有英文稿：中度逻辑与语言优化；默认输出架构与证据诊断。
- 单段文本：优先保留原段落边界。
- 全文或完整章节：在用户允许时重排原文已有环节，不增加新的科学连接。
- 论文类型不明确：先保持句段级精修，同时在诊断中列出可能的主线类型及其依据。

## 使用边界

本技能负责表达、论证结构和证据边界的编辑，不替代实验设计或作者的科学判断。原文缺少比较基准、时间顺序、中间变量、直接机制证据或适用条件时，精修稿保留可确定内容，并在“需作者确认的问题”中说明缺口及其影响。
