# 金属材料论文高频语言问题与领域书写规范（v5）

本文件收录金属材料稿件（尤其是中文母语作者的英文稿）中反复出现的语言问题及对应的领域书写规范。所有修正都不改变科学含义；含义可能改变的替换列入作者确认项。

## 1. 图表引用句式

### 1.1 问题模式

| 高频原句 | 问题 | 改法 |
|---|---|---|
| It can be seen from Fig. 2 that the strength increases. | 空转主语，信息后置 | The strength increases with aging time (Fig. 2). |
| As shown in Fig. 3, it is obvious that... | 双重引导 + 评价词 | Fig. 3 shows that... 或直接陈述 + (Fig. 3) |
| Fig. 4 shows the SEM images of the samples. | 图注式句子占据正文 | 正文写图建立的判断，图内容留给图注 |
| From the above results, we can conclude that... | 冗余过渡 | These results indicate that... |

### 1.2 规则

1. 图表引用优先放在句末括号：`(Fig. 2a)`、`(Table 1)`；
2. 每段落中 `As shown in Fig. X` 至多出现一次，其余改为括号引用；
3. 正文句子的主语是材料、组织、性能或过程，不是 "Fig. X" 本身，除非确在谈论图的呈现方式。

## 2. 时态规范

| 内容 | 时态 | 示例 |
|---|---|---|
| 本文做过的操作与测量 | 过去时 | Specimens were aged at 500 °C. |
| 本文观察到的结果 | 过去时 | The yield strength increased from 850 to 1020 MPa. |
| 图表当前呈现的内容 | 现在时 | Fig. 3 shows the lattice strain evolution. |
| 公认的物理事实与常识 | 现在时 | Dislocations glide on close-packed planes. |
| 由本文结果建立的一般性结论 | 现在时（有证据时） | These results indicate that Cu additions alter the load partitioning. |
| 文献中他人的具体工作 | 过去时或现在完成时 | Ritchie and Knott reported...; Several studies have shown... |

常见错误：全文单一过去时（把公认事实也写成过去时），或全文单一现在时（把本文特定观察写成普适规律）。混用导致证据强度漂移时列入修正。

## 3. 冠词与单复数

### 3.1 相与组织的冠词

- 特指某一相：`the α phase`、`the β matrix`、`the Ti₂Cu precipitates`；
- 泛指一类组织行为：`grain boundaries impede dislocation motion`（无冠词复数）；
- 首次引入用不定冠词或复数，再次提及用定冠词。

### 3.2 高频不可数名词

`research`（不用 researches 表示"多项研究"，改 studies）、`equipment`、`information`、`behavior`（一般不可数；比较多种行为时可用 behaviors）、`deformation`（过程不可数）、`microstructure`（谈单一状态用单数；比较多种状态可用 microstructures）。

### 3.3 高频错误

| 原句 | 改法 |
|---|---|
| The sample was observed by SEM. | The sample was examined by SEM. / SEM observations were performed. |
| Many researches have studied... | Many studies have investigated... |
| The mechanical property of the alloy is excellent. | 指多项性能时：mechanical properties；且需具体指标替代 excellent |

## 4. 评价词与模糊量词

| 高频词 | 问题 | 处理 |
|---|---|---|
| obvious / obviously | 主观评价，无信息 | 删除，或改为定量差异 |
| more and more | 口语化 | increasing / increasingly |
| very / quite / relatively（无基准） | 无锚点 | 给出数值或比较对象，或删除 |
| significant(ly) | 可能被读作统计显著 | 有统计检验保留；否则 marked / pronounced / considerable |
| about / around（正式度不足时） | 可换 | approximately / ~（图表中） |
| huge / dramatic | 宣传语气 | 定量描述 |
| superior comprehensive mechanical properties | 中式套语 | 列出具体指标组合及条件 |
| has attracted extensive attention | 空泛开场 | 直接陈述领域问题 |
| plays an important role in | 万能句 | 写明具体作用方式 |

## 5. 动词搭配

| 名词 | 规范动词 | 避免 |
|---|---|---|
| experiment / test | perform, conduct, carry out | do, make |
| measurement | perform, make | do |
| microscopy / characterization | perform; examine (对象) | observe the SEM |
| heat treatment | subject to, apply | do heat treatment |
| tensile test | conduct; test (材料) was tested | 材料 "was stretched" |
| strength / hardness | increase, decrease, reach | improve（指标本身用 increase；improve 用于性能整体） |
| crack | initiate, propagate, arrest, deflect | happen, grow up |
| precipitate (v.) | form, nucleate, coarsen | appear（可用但弱） |
| dislocation | glide, pile up, accumulate, annihilate | move around |

## 6. 领域符号与单位规范

### 6.1 单位

- 数值与单位间加空格：`850 MPa`、`500 °C`、`10 μm`（例外：`90°` 角度、`%`按期刊惯例）；
- 复合单位用负指数或斜线全篇统一：`kg·m⁻³` 或 `kg/m³`；
- 区间：`500–600 °C`（en dash），单位写一次；
- 作定语时连字符化：`a 10-μm-thick layer`，但表语不连字符：`the layer is 10 μm thick`；
- `wt.%`、`at.%` 全文统一写法并前置说明（如 "all compositions in wt.% unless noted"）。

### 6.2 晶体学记法

- 晶面 `(111)`，晶面族 `{111}`；晶向 `[110]`，晶向族 `⟨110⟩`；
- 六方晶系四指数 `(0001)`、`{101̄0}` 与三指数不混用；
- 取向关系用 ∥ 与规范格式：`(0001)α ∥ {110}β, ⟨112̄0⟩α ∥ ⟨111⟩β`；
- 相名称希腊字母正体（α、β、γ、δ、ε、ω），变量斜体（*σ*、*ε*、*K*）；上下标格式全篇统一（σ_y、K_IC、ΔK_th）。

### 6.3 材料命名

- 牌号首次出现给出名义成分：`Ti–6Al–4V (wt.%)`；成分连接号用 en dash；
- specimen 与 sample 全篇统一（力学试样多用 specimen，材料/粉末批次多用 sample）；
- 状态命名（as-cast、as-built、solution-treated、peak-aged）作定语时连字符化并全篇统一。

## 7. 指代与修饰

### 7.1 悬垂结构

| 原句 | 问题 | 改法 |
|---|---|---|
| Using TEM, the precipitates were observed. | 分词悬垂（TEM 的执行者不是 precipitates） | TEM observations revealed the precipitates. / Using TEM, we observed... |
| After aging for 8 h, the hardness increased. | 可接受（惯用），但主语最好是被处理对象 | After aging for 8 h, the alloy hardened... |
| Compared with the base alloy, the strength of the modified alloy... | 比较对象错位（strength vs alloy） | Compared with that of the base alloy, the strength... |

### 7.2 指代唯一性

- `it`、`this`、`which` 的先行词必须唯一；`this` 后接名词锚定：`this transition`、`this strengthening effect`；
- `the former / the latter` 仅在两项且距离近时使用；
- `respectively` 仅当两组序列一一对应且顺序明确时使用，且置于句末。

## 8. 句式冗余压缩

| 冗余 | 压缩 |
|---|---|
| due to the fact that | because |
| in order to | to |
| it is worth noting that / it should be noted that | 直接陈述（或 notably，限一次） |
| a large number of | many / numerous |
| carry out an investigation on | investigate |
| make a comparison between | compare |
| in the present study/work（每段重复） | 全文 ≤2 次，指代清楚时删除 |
| has the ability to | can |
| in the case of | for / under |

## 9. 逻辑连接词的强度

- `therefore / thus / hence` 只用于前句证据确实支持后句结论处；装饰性使用删除；
- `meanwhile`（中文"同时"直译）多数应为 `in addition` / `simultaneously`（仅当真正同时发生）；
- `on the contrary` 表示反驳预期；单纯对比用 `in contrast / by contrast`；
- `besides` 口语化，改 `in addition / moreover`；
- `what's more` 不用于论文。

## 10. 中译英高频陷阱

| 中文习惯 | 直译问题 | 规范表达 |
|---|---|---|
| 组织 | organization（误） | microstructure |
| 性能 | performance（泛） | properties（材料性能）/ performance（服役表现），按语境 |
| 强度和塑性的匹配 | match of strength and plasticity | strength–ductility combination / synergy（有证据时） |
| 细化晶粒 | thin the grains | refine the grains / grain refinement |
| 析出相弥散分布 | dispersedly distributed | uniformly dispersed precipitates |
| 断口形貌 | fracture appearance | fracture surface / fractography |
| 疲劳寿命提高了 X% | improved X%（歧义） | increased by a factor of... / increased by X%（明确基准） |
| 本文研究了 | This paper studied | 主语换研究对象或 we；paper 不执行研究动作（This study examines 可用） |
| 归因于 | be blamed on | be attributed to（注意归因需证据等级支持） |
| 揭示了……机理 | revealed the mechanism（常超证据） | 按 L0–L7 校准：provide insight into / identify / elucidate |
