# Introduction 专用逻辑与重构模式（v5 · 发现/需求双路由扩展）

本模式用于润色、提升和重构金属材料论文的 Introduction。它把引言视为一段围绕主要贡献展开的科学论证：先说明结果变量为何重要，再限定已有认识能够解释或实现到哪里，随后切出一个与本文最高层贡献同级的精确缺口，最后用本文的核心新认识、证据路线和适用边界闭合该缺口。

本模式吸收高水平材料论文中可迁移的逻辑组织方式。只迁移段落功能、论证依赖、缺口精度和证据推进方式，不复制任何论文的可识别词句、具体机制、数据、取向关系或工艺排列。

## 1. 启用条件

当出现以下任一情况时加载本文件：

- 用户提供 Introduction 草稿并要求润色、提升、重构、收束或增强逻辑；
- 用户要求围绕主要贡献或 `new insight` 重写引言；
- 用户要求判断引言属于发现导向还是需求与性能导向；
- 用户要求提炼精确知识缺口、重写引言末段或检查文献综述是否服务主线；
- 用户提供摘要、结果、讨论或结论，要求据此反向生成 Introduction；
- 用户要求检查引言与题目、摘要、首图、Results、Discussion 和 Conclusion 是否采用同一主张集合。

以下情况只做可确定范围内的诊断，不静默补写：

- 只提供引言草稿，且草稿没有说明本文的主要贡献；
- 文献支撑范围不清，无法判断某一引用是否支持拟写命题；
- 摘要、结果和结论对主要贡献的表述相互冲突；
- 本文核心机制依赖未提供的实验或计算结果；
- 用户要求补充最新文献，但没有授权检索或没有提供文献材料。

## 2. Introduction 的底层任务

高水平 Introduction 需要完成一条可核查的必要性论证：

```text
重要结果、现象或能力 Y
→ 当前共识或主要策略 A
→ A 在具体条件 C 下的边界
→ 与本文贡献同级的精确缺口 B
→ 本文的关键变量或状态 X
→ X 通过过程 M 改变 Y
→ 对应每个箭头的证据路线 E
→ 新增的解释、预测或设计能力 G
```

引言前半段通常从 `Y` 反向收缩到 `B`，引言末段再从 `X` 沿 `M`、`E` 和 `G` 正向展开。

这一顺序使背景、文献、缺口、方法和本文贡献形成依赖关系。任何不能支撑 `X → M → Y` 主线的信息都应压缩、后移或删除。

## 3. 写作前填写的八项工作变量

在改写完整段落前，先填写以下内容。变量只用于组织工作，不替代正式科学表述。

| 变量 | 必须回答的问题 | 典型内容 |
|---|---|---|
| `Y` | 本文最终解释、调节或实现什么？ | 相变结果、析出行为、强塑协同、热膨胀系数、损伤模式、预测能力 |
| `A` | 当前最接近的公认解释或设计策略是什么？ | 已知机制、现有工艺、主要控制因素、常规温度行为 |
| `C` | 当前认识或策略在哪个边界内失效？ | 特定相、温度、尺度、成分、时间阶段、服役条件或制造约束 |
| `B` | 精确缺失的是哪一个关系或环节？ | 前驱状态、形核路径、定量贡献、耦合作用、实现步骤或适用条件 |
| `X` | 本文发现或操控的关键变量、状态或路径是什么？ | 溶质团簇、成分调制、纳米相变、电子结构、界面状态 |
| `M` | `X` 怎样改变 `Y`？ | 结构模板、析出路径、软化补偿、载荷分配、声子—弹性耦合 |
| `E` | 哪些证据分别支持各主要箭头？ | 直接观察、受控比较、原位表征、定量模型、独立计算、性能验证 |
| `G` | 这一认识增加了什么能力？ | 解释异常、连接初态与终态、定量归因、精确调控、可规模化实现 |

如果 `B` 不能用一句可回答的问题表达，缺口通常仍然过宽。如果 `X → M → Y` 只能写成方法清单、结果清单或性能数字，主要贡献仍未提炼到合适层级。

## 4. 两类主要引言路由

### 4.1 发现导向

发现导向回答：

> 在特定条件下，现有知识为什么无法解释该现象，或为什么无法连接已知初态与终态？

适用情形包括：

- 发现与常规预期冲突的新现象；
- 揭示相变、析出、变形或损伤中的隐藏前驱状态；
- 解析已知初态和终态之间缺失的机制路径；
- 建立新的定量关系、控制因素或边界条件；
- 解释已有理论在特定相、尺度或温度区间内为什么失效。

其逻辑主干为：

```text
重要现象或过程
→ 正常预期、已知终态或当前解释
→ 在条件 C 下出现知识断点
→ 精确机制问题 B
→ 本文发现 X
→ X 通过 M 导致或解释 Y
→ 证据链与认识边界
```

### 4.2 需求与性能导向

需求与性能导向回答：

> 如何在明确的材料、制造或服役约束下，实现、控制或预测目标能力？

适用情形包括：

- 强度—塑性、强度—韧性、低模量—疲劳等多性能协同；
- 工业尺度、块体尺寸、低成本、稳定性或可制造性约束；
- 目标组织、缺陷状态或功能范围的精确调控；
- 多因素共同控制物性的定量分解；
- 从定性机制认识推进到可计算、可预测或可设计关系。

其逻辑主干为：

```text
目标能力或性能 Y
→ 已知设计原理或控制因素 A
→ A 在约束 C 下的实现或定量瓶颈 B
→ 本文采用的可控变量 X
→ X 建立关键中间状态或过程 M
→ 组织、物性或性能结果 Y
→ 实施范围与设计能力 G
```

### 4.3 混合论文的处理

许多高水平论文同时包含机制发现和性能提升。引言仍应选择一个首要问题：

- 论文的身份由“解释未知过程”决定时，以发现导向为主，性能作为后果层；
- 论文的身份由“在约束下获得目标能力”决定时，以需求与性能导向为主，机制作为解释层；
- 定量归因论文根据首要问题选择路由：以理解未知贡献为主时属于发现导向，以精确调控为主时属于需求与性能导向；
- 两条贡献无法汇合到同一上位命题时，不强行压成单一故事，保留主次关系并明确第二贡献的边界。

自动路由时执行以下检查：

1. 删除性能数字后，是否仍有一条可独立成立的新现象、新关系或新机制？
2. 删除完整机制细节后，设计动作、目标状态和能力提升是否仍构成论文的主要贡献？
3. 题目和摘要首先承诺的是认识增量还是能力增量？
4. 前两幅主图首先证明异常、前驱状态和机制路径，还是设计变量、目标组织和性能范围？

## 5. 四类高价值精确缺口

### 5.1 预期冲突

适用于异常现象和新物性发现。

```text
现有理论或经验预测 Y0
→ 在条件 C 下观测到 Y1
→ 现有解释无法说明 Y0 与 Y1 的差异
```

写作要求：

- 先把正常预期及其依据讲清楚；
- 明确异常发生的相、温度、尺度或成分区间；
- 缺口落在“持续软化来自哪里”“哪个隐藏状态改变了正常行为”等可检验问题；
- 不用 unusual、unexpected 或 unprecedented 代替正常基线和观测差异。

### 5.2 机制路径缺失

适用于相变、析出、变形、损伤和失效研究。

```text
初态已知
→ 中间过程未知
→ 终态已知
```

强缺口应同时说明：

1. 已知初态和终态；
2. 前人已经观察到的形貌、位置、取向或阶段；
3. 尚未解析的具体形核、生长、转变或损伤步骤；
4. 既有方法为什么无法捕捉该步骤；
5. 本文方法将补足哪一个缺失可观测量。

### 5.3 定量归因缺失

适用于多个因素共同控制物性或性能的问题。

```text
Y = f(X1, X2, ...)
```

已有研究可能已经确认 `X1` 和 `X2` 均有作用，真正缺失的是：

- 各自贡献的大小；
- 作用方向及符号；
- 随成分、温度或结构变量变化的敏感性；
- 二者之间的耦合项；
- 哪一因素主导调控趋势，哪一因素增强、削弱或交叉连接。

“机制复杂”“多因素共同作用”不能替代可分解的定量问题。

### 5.4 工程实现缺失

适用于材料设计、制造和性能导向论文。

```text
物理原理已知
+ 目标能力明确
+ 在约束 C 下缺少可实施路径
```

约束可以包括：

- 块体尺寸或工业规模；
- 工艺复杂度、成本和节拍；
- 组织均匀性、稳定性和重复性；
- 调控范围、服役温度和加载条件；
- 多性能之间的通常代价；
- 商业合金、现有设备或真实构件兼容性。

精确缺口应写成“如何利用何种可控中间变量，在何种约束下建立目标组织或能力”，不能只写“性能仍需提高”。

## 6. 先写最高层贡献的因果句

在撰写 Introduction 前，先完成以下工作句：

```text
在条件 C 下，关键变量或状态 X 通过过程 M 改变结果 Y；
证据 E1 证明 X 存在或被成功建立，
证据 E2 支持 X → M，
证据 E3 将 M 与 Y 联系起来，
由此获得解释、预测或设计能力 G。
```

这句话不是摘要，也不是引言末段的固定句式。它用于确定全文最高层贡献和引言的逻辑终点。

### 6.1 合适的贡献层级

| 表述 | 问题 | 处理 |
|---|---|---|
| We characterized the microstructure using TEM and DFT. | 方法主导，未说明新增关系 | 继续提取 `X → M → Y` |
| The alloy exhibited high strength and ductility. | 结果主导，缺少设计或机制增量 | 说明性能为何同时获得 |
| Solute clustering creates a local structural and chemical precursor for β nucleation. | 变量、过程和结果关系清楚 | 可统领发现型引言 |
| Retained concentration modulation activates distinct precipitation pathways in a bulk alloy. | 可控变量与组织形成路径清楚 | 可统领设计型引言 |

### 6.2 缺口与贡献必须处于同一层级

- 贡献是新机制，缺口落在具体机制步骤；
- 贡献是新前驱状态，缺口落在形成前缺失的状态或可观测量；
- 贡献是定量关系，缺口落在贡献大小、符号或耦合项；
- 贡献是设计能力，缺口落在明确的制造、性能或调控约束；
- 贡献是新现象，缺口落在正常预期与观测结果之间的冲突。

“相关研究较少”“机制尚不清楚”“性能仍需提升”缺少可判别性，不能独立承担核心缺口。

## 7. 从主要贡献反向生成 Introduction

### 7.1 锁定结果变量 `Y`

先确定论文最终解释或优化的对象：

- 哪个结果会出现在题目、摘要核心句或结论第一条？
- 该结果是现象、过程、性能、物性、失效模式还是预测能力？
- 读者读完论文后应能回答哪个问题？

开篇只建立与 `Y` 直接相关的科学或工程价值。

### 7.2 提取当前共识 `A`

只选择后文提出 `X → M → Y` 所必需的已有认识：

- 已知机制为什么能够解释正常行为；
- 当前设计策略为什么原则上能够改善目标性能；
- 哪些控制因素已经被定性识别；
- 哪个最近邻体系已经得到较完整研究。

背景知识的取舍标准是：删除该信息后，读者是否仍能理解精确缺口和本文贡献。答案为“是”时，该信息通常不应展开。

### 7.3 明确失效条件 `C`

将问题限定到具体边界：

- 特定晶体结构、相或成分区间；
- 特定温度、应变率、循环阶段或环境；
- 原子、纳米、晶粒或构件尺度；
- 商业合金、块体制造或工业实施条件；
- 定性认识向定量调控推进的阶段。

没有 `C` 时，引言容易把局部问题写成整个领域都未解决的问题。

### 7.4 审计已有研究的终点

用连续的两个命题回答：

1. 已有工作已经证明或实现了什么？
2. 已有工作停在了哪一个具体步骤？

强表达通常包含三部分：

```text
前人已经回答的内容
+ 尚未回答的具体关系
+ 尚未回答的原因或方法边界
```

例如，前人已经确定析出相的形貌和空间位置，但受空间分辨率和化学敏感性限制，无法解析形核前驱状态及后续生长路径。

### 7.5 把缺口写成可回答的问题 `B`

合格的缺口可以被一个明确实验、计算或受控比较回答，例如：

- 新相形成前是否存在可直接观察的溶质或结构前驱状态？
- 稳定马氏体在转变终了温度以下从哪里获得持续模量软化？
- 声子项和弹性项分别贡献多少，哪一项主导调控趋势？
- 哪种可控成分状态能够在块体商业合金中同时激活不同析出路径？

当缺口仍需要使用“很多因素”“复杂机制”或“进一步研究”才能描述时，应继续收缩。

### 7.6 将核心新认识转化为可检验预测

如果 `X → M → Y` 成立，应至少产生两个可核查预测：

- `X` 在 `Y` 发生前或目标组织形成前应可被观察或量化；
- `X` 所在区域应具有与 `M` 一致的化学、结构、能量或力学特征；
- 改变 `X` 应引起 `M` 或 `Y` 的系统变化；
- 不同证据方法应在同一箭头上相互印证；
- 目标性能应在规定条件和对照下随目标状态出现。

这些预测决定本文方法和结果在引言末段中的顺序。

### 7.7 确定外延 `G`

引言结尾返回开篇的 `Y`：

- 新机制提高了哪种解释或预测能力？
- 新定量关系支持了何种精确调控？
- 新设计路径满足了哪些明确约束？
- 新现象扩展了哪一条已有认识的适用范围？

外延强度受证据限制。模型合金中的机制可以对含适合溶质的同类合金提出可能适用性，不能自动写成适用于所有金属材料。

## 8. 文献综述的组织规则

### 8.1 文献按论证功能分组

引言文献主要承担四类任务：

| 功能 | 文献需要支持的命题 |
|---|---|
| 重要性 | `Y` 为什么影响关键性能、物性或应用 |
| 当前共识 | `A` 是什么，已有解释或策略如何工作 |
| 最近前沿 | 与本文最接近的问题已经解决到哪里 |
| 精确缺口 | 哪个步骤、定量关系、尺度连接或实现环节仍缺失 |

避免按年份、作者或表征方法逐篇罗列。每组文献应共同支持一个清楚命题。

### 8.2 优先使用最近邻对照

优先比较差异最小的对象：

- 相同材料家族中的不同马氏体结构；
- 相同物性中的各向同性与各向异性情形；
- 相同设计原理在实验室尺度与块体商业合金中的实现；
- 正常温度行为与特定成分区间内的异常行为；
- 已知终态与缺失的形成前阶段。

最近邻对照能够把缺口压缩到一个关键变量，减少宽泛背景。

### 8.3 引文范围不得漂移

重排文献时必须保持：

- 引文仍紧邻其实际支撑的命题；
- 同一引文组合没有被扩大到更强、更宽或不同层级的结论；
- 综述性引文与原始研究引文的功能保持区分；
- 文献只观察到形貌时，不改写为已经建立形核机制；
- 文献只报告关联时，不改写为控制关系；
- 未经检索范围支持，不新增 first、only、unprecedented 或 to the best of our knowledge。

用户未要求检索时，不新增原文没有的文献。现有引文不能可靠支持拟写命题时，保留可确定内容并列入作者确认项。

## 9. 方法必须对应缺失的可观测量

方法只在精确缺口之后出现，并说明它补足了什么：

```text
缺少原子尺度化学敏感性
→ 原子分辨化学成像与计算

缺少连续温度演化信息
→ 原位冷却或加热表征

缺少多因素定量分解
→ 可控变量序列、张量或参数分解与独立实验验证

缺少工业尺度组织实现路径
→ 计算指导的工艺设计、块体实验和性能验证
```

引言末段不堆叠仪器名称。只保留能够说明证据能力的主要方法，其余方法进入 Methods。

## 10. 三段式与四段式组织

### 10.1 三段式

适用于 PRL、短通讯、Scripta Materialia 和问题相对集中的论文。

#### 第一段：价值与共识

```text
Y 为什么重要
+ 当前通过 A 如何理解或实现 Y
```

段末应落到与本文直接相关的物理过程、组织变量或性能瓶颈。

#### 第二段：边界与精确缺口

```text
A 在 C 下为什么不足
+ 最近邻研究已经到达的终点
+ 尚未回答的关系 B
+ 既有方法或实现路径的限制
```

#### 第三段：本文的回答

```text
研究体系与必要方法
→ X
→ M
→ Y
→ E 的证明顺序
→ G 与适用边界
```

### 10.2 四段式

适用于 Acta Materialia、International Journal of Plasticity 等全长论文。

1. 研究价值和当前共识；
2. 与本文最接近的已有研究及其已解决内容；
3. 已有研究的具体边界、方法限制和精确缺口；
4. 本文的体系、核心新认识、证据路线、主要结果和意义。

第二、三段可以合并，条件是读者仍能清楚区分“已知到哪里”和“具体缺什么”。

### 10.3 段落功能检查

每段只承担一个主要推进任务：

- 段首给出当前段的问题或命题；
- 中间句提供必要共识、文献或限制；
- 段末把信息推向下一层更具体的问题；
- 相邻段之间存在知识依赖，不能仅靠 However、Nevertheless 或 Recently 连接；
- 删除任一段后，应能够明确指出哪一个必要前提、缺口或回答消失。

## 11. 引言末段的组织

引言末段应按照因果和证据依赖顺序预告全文：

```text
研究对象或干预
→ 关键状态 X 被发现或建立
→ 中间过程 M
→ 最终现象、组织、物性或性能 Y
→ 证据方法 E
→ 解释、调控或实施能力 G
```

推荐保留以下内容：

- 为什么选择该材料或变量序列；
- 本文回答的精确问题；
- 一句话最高层核心新认识；
- 2–4 个按照正文顺序排列的关键证据或结果；
- 与开篇目标对应的科学或工程意义；
- 必要的材料、尺度、温度或制造边界。

不应把引言末段写成：

- 完整实验步骤；
- 仪器和软件清单；
- 所有性能数字和所有组织尺寸的集合；
- 结果段的提前复制；
- 与正文证据不一致的机制结论；
- 空泛的 provide new insight、pave the way 或 broad applications。

## 12. 两类路由的可复用段落模板

以下模板只规定功能，实际句子必须由用户材料和引文支持。

### 12.1 发现导向

#### 第一段

```text
[Process/property] in [material class or condition] determines [important scientific or engineering consequence].
Current understanding attributes this behavior to [established mechanism or normal expectation].
```

#### 第二段

```text
Previous studies have established [closest known endpoint or neighboring system].
Under [condition C], however, they have not resolved [specific relation B].
Existing evidence primarily identifies [known morphology, location, endpoint, or correlation], while [missing precursor, pathway, quantitative contribution, or scale connection] remains unobserved because [specific limitation].
```

#### 末段

```text
Here, we investigate [system selected to discriminate the alternatives] using [methods matched to the missing observables].
We show that [X + evidence-calibrated verb + M or Y].
The evidence establishes [E1], [E2], and [E3] in the order required to connect [initial state] to [final state or phenomenon].
These results [specific explanatory or predictive gain G] within [boundary].
```

### 12.2 需求与性能导向

#### 第一段

```text
Achieving [target capability Y] under [application or service condition] is important for [specific consequence].
Existing strategies use [A] to improve [target property] through [established physical basis].
```

#### 第二段

```text
The practical or quantitative use of this strategy is limited by [constraint C].
Available approaches can achieve [established result], yet they cannot [specific capability B] under [scale, cost, stability, or multi-property requirement].
This limitation calls for direct control of [key intermediate variable].
```

#### 末段

```text
Here, we use [controllable variable X] to establish [intermediate state M] in [material or processing boundary].
This route produces [target organization or property state] and delivers [quantitative result Y under conditions].
[Evidence groups] verify the formation process, the relevant deformation or physical mechanism, and the performance consequence.
The resulting relation provides [specific design or implementation gain G] within [boundary].
```

### 12.3 定量归因型

```text
[Property Y] is known to depend on [X1] and [X2].
Previous work has established their qualitative importance, but their respective contributions, signs, sensitivities, or coupling remain unquantified under [C].
Here, a controlled material or variable series is used to separate [terms or factors].
The analysis identifies which factor governs the tuning trend, which factor enhances or weakens the response, and how their interaction produces the measured range.
```

## 13. 句级和段内重构规则

### 13.1 每句只有一个主要功能

Introduction 中的句子通常承担以下功能之一：

- 定义研究对象或结果变量；
- 说明科学或工程重要性；
- 建立当前共识；
- 报告最近邻研究的已知终点；
- 限定失效条件；
- 切出精确缺口；
- 说明方法边界；
- 提出本文问题、核心新认识、证据路线或意义。

一句同时承担背景、文献、缺口、方法和结果时应拆分或重排。

### 13.2 已知信息在前，新问题在后

每句从当前段已经建立的对象出发，句末放置更具体的限制、缺口或本文新增关系。段落应逐步收缩，不能在材料、应用、组织、机制和方法之间反复跳转。

### 13.3 主题词保持稳定

同一段落围绕一个结果变量、过程或关键对象推进。不要为了词汇变化频繁更换准确术语，也不要使用 broad challenge、complex mechanism、promising strategy 等宽泛词替代具体变量。

### 13.4 转折必须有实质差异

However、Nevertheless、Yet 和 In contrast 只在前后命题存在真实边界、冲突或知识不对称时使用。普通补充、时间推进和同类例证不使用强转折。

### 13.5 段末形成下一问题

段末优先落在：

- 尚未观察的状态；
- 尚未连接的两个阶段；
- 尚未分解的贡献；
- 尚未满足的工程约束；
- 本文需要测量的关键变量。

段末不重复段首的重要性陈述。

## 14. 科学与引文安全边界

### 14.1 不生成缺失的科学连接

不得：

- 从摘要或结果中的并列观察生成新的因果链；
- 把不同样品、区域或温度点自动写成连续演化路径；
- 把方法分辨率优势写成已经证明机制；
- 把相关性写成主导或控制关系；
- 把局部模型合金结果扩展为全部同类合金；
- 为形成完整故事补写未测量的中间状态；
- 为增强必要性夸大整个领域的知识缺口。

### 14.2 缺口强度受文献材料约束

可以确定的范围按以下顺序表达：

- 前人尚未直接观察某一状态；
- 前人尚未区分两个可能路径；
- 前人尚未定量分解两个贡献；
- 前人方法无法在所需尺度或条件下解析该关系；
- 当前策略无法在明确约束下实现目标能力。

只有提供充分检索依据时才使用 never reported、first observation、unprecedented 或 unexplored。

### 14.3 本文末段的动词校准

- `observe`、`measure`、`identify`：直接证据；
- `reveal`、`show`：存在清楚证据链，但仍需检查宾语是否超过数据；
- `precede`：具有可靠时序；
- `contribute to`、`promote`：存在可测贡献或受控比较；
- `lead to`、`induce`：具有中间过程和独立验证；
- `govern`、`control`、`dominate`：主要替代解释已经处理；
- `enable`：设计动作、中间状态和能力后果闭合；
- `provide a route`：适用条件和实施边界明确。

## 15. 与首图和正文的闭合

Introduction 与首个核心图应共享同一证明结构：

- 异常发现型：首图尽早展示正常基线与异常现象；
- 机制路径型：前几幅图依次展示前驱状态、胚胎或中间态、后续生长或终态；
- 定量归因型：首图展示可控变量对应的连续趋势或调控范围；
- 设计实现型：首图展示设计变量、关键中间状态和目标组织或能力之间的路径。

引言末段的结果顺序应与正文证据顺序一致。正文不能先证明后果、再回头补充决定核心机制的前驱状态，除非论文体裁和数据依赖确实要求该顺序。

## 16. 四类标定案例的抽象逻辑

本模式由以下四类高水平 Introduction 的共同组织方式标定：

| 案例类型 | 首要问题 | 精确缺口 | 引言闭合方式 |
|---|---|---|---|
| 异质结构商业钛合金 | 如何在工业约束下获得强塑协同 | 异质结构原理已知，但缺少适用于块体商业合金的简便、可控路径 | 成分调制 → 多析出路径 → 异质组织 → 强塑协同与可实施性 |
| α″ 马氏体中 β 析出 | β 相如何形核、生长并形成变体 | 初态和终态已知，形核前驱状态及生长路径缺失 | 溶质团簇 → 局部 β 型结构 → β 胚胎 → 晶格旋转与变体演化 |
| Elinvar 马氏体 | 为什么稳定马氏体在转变终了温度以下不发生常规硬化 | 正常冷却硬化预期与近温度无关模量冲突 | 双纳米马氏体 → 缓慢位移型转变 → 软化补偿 → 恒模量 |
| MZr2 轴向热膨胀 | 如何定量理解并调节宽范围热膨胀系数 | 声子和弹性作用已知，各自贡献及耦合作用未定量 | 可控电子结构 → Grüneisen 参数和弹性顺应性 → 定量贡献 → 连续调控 |

这些案例只用于说明缺口类型和因果层级。实际重构不得复制其具体句子、机制、数据或材料身份。

## 17. Introduction 专用输出模式

### 17.1 仅精修引言

只输出连续、可直接用于论文的 Introduction。保留原有引文编号和可确定的支撑范围。

### 17.2 精修引言与关键说明

输出：

1. 精修后的 Introduction；
2. 一句话核心新认识；
3. 判定的主路由与精确缺口类型；
4. 影响逻辑层级、引文范围、贡献强度或段落顺序的关键修改。

### 17.3 Introduction 完整模式

#### 一、重构后的 Introduction

给出连续文本。

#### 二、一句话核心新认识

采用 `C 下的 X → M → Y` 关系，并标注最高证据等级。

#### 三、八项工作变量

列出 `Y、A、C、B、X、M、E、G`，无法确认的项目明确说明缺少什么材料。

#### 四、段落功能映射

逐段说明：

- 本段回答的问题；
- 使用的共识或最近邻文献；
- 段末推进到的下一问题；
- 与下一段的依赖关系。

#### 五、缺口—贡献同级检查

说明精确缺口是否与最高层贡献处于同一层级，以及删除或降低了哪些宽泛缺口。

#### 六、引文与证据边界

列出：

- 引文移动或保留的理由；
- 不能确认支撑范围的引用；
- 本文末段各核心动词的证据上限；
- 未补写的文献、机制和中间状态。

#### 七、需作者确认的问题

每项说明缺失材料及其影响。没有时写“无”。

### 17.4 Introduction 架构诊断模式

不重写正文，只输出：

1. 主路由和核心问题；
2. 一句话最高层贡献；
3. 当前各段功能；
4. 背景过宽、最近邻对照缺失、缺口过宽或方法清单化的位置；
5. 建议的三段式或四段式顺序；
6. 需要作者补充的贡献、证据或引文信息。

## 18. Introduction 专用输入字段

用户可提供：

- Introduction 模式：自动 / 发现导向 / 需求与性能导向；
- 目标期刊与目标长度；
- 现有 Introduction 草稿；
- 题目、摘要、Results、Discussion 和 Conclusion；
- 作者认定的一句话主要贡献；
- `Y`：最终解释或优化的结果；
- `A`：当前共识或主要策略；
- `C`：现有认识失效的具体条件；
- `B`：精确知识、定量或实现缺口；
- `X`：本文关键变量、状态或设计；
- `M`：连接 `X` 与 `Y` 的过程；
- `E1–E3`：直接观察、机制证据和结果验证；
- `G`：新增解释、预测、调控或实施能力；
- 必须保留的引文组和固定表述；
- 允许段内、跨段或跨小节重排的权限；
- 是否允许删除重复背景或压缩方法细节；
- 是否需要新增文献检索。

只提供 Introduction 草稿时，以草稿中可确认的内容为上限。提供摘要、结果、讨论和结论时，优先以这些部分已经建立的主张和证据确定引言终点。

## 19. 内部执行顺序

输出前完成：

1. 锁定数值、术语、引文编号、材料状态和结论强度；
2. 从题目、摘要、结果、讨论和结论中提取最高层贡献；
3. 判定发现导向或需求与性能导向，记录主次关系；
4. 填写 `Y、A、C、B、X、M、E、G`；
5. 检查 `B` 与最高层贡献是否同级；
6. 审计每段和每句的实际功能；
7. 将现有文献按重要性、共识、最近前沿和精确缺口分组；
8. 选择最近邻对照并删除无功能文献罗列；
9. 将方法逐一对应到缺失可观测量；
10. 选择三段式或四段式；
11. 先构建各段功能句，再写连续文本；
12. 按 `X → M → Y → E → G` 重写引言末段；
13. 校准核心动词和推广边界；
14. 核对引言末段、首图和正文证明顺序；
15. 核对题目、摘要、Introduction、Results、Discussion 和 Conclusion 的主张集合；
16. 列出不能由现有材料确认的文献支撑、机制和外延。

不得输出内部逐步推理。可以输出段落功能映射、证据审计和具体修改理由。

## 20. 最终核查

- [ ] 一句话最高层贡献能够写成 `C 下的 X → M → Y`。
- [ ] 开篇建立的是与 `Y` 直接相关的价值，没有通用背景堆叠。
- [ ] 当前共识 `A` 足以理解缺口，且没有无关综述。
- [ ] 失效条件 `C` 明确到相、温度、尺度、成分、阶段或工程约束。
- [ ] 精确缺口 `B` 可以被本文实验、计算或比较直接回答。
- [ ] `B` 与最高层贡献处于同一逻辑层级。
- [ ] 已有研究回答到哪里、停在哪里及为什么停下均得到说明。
- [ ] 最近邻对照能够突出一个关键变量。
- [ ] 每种主要方法对应一个缺失可观测量。
- [ ] 引言末段按照正文证据顺序预告 `X、M、Y、E、G`。
- [ ] 引文仍支撑原有命题，没有因重排扩大范围。
- [ ] 没有新增未提供的文献、数据、机制或优先权主张。
- [ ] 每段只有一个主要推进任务，段末形成下一问题。
- [ ] 替换检验通过：将末段换成同领域另一篇论文时，前文不能仍然完全适用。
- [ ] 首尾闭合：结尾返回开篇的 `Y`，并给出受证据约束的 `G`。
- [ ] 首图或前两幅主图与引言承诺的证明顺序一致。
- [ ] 需要新增文献、实验或作者判断的内容已进入确认项。
