# 精修与科学论证质量核查表（v5 · 摘要双路由与 Introduction 扩展）

## 1. 科学信息锁定

- [ ] 数值、单位、误差、有效数字和统计量与原文一致。
- [ ] 材料牌号、成分、相名称、组织状态和取向未改变。
- [ ] 工艺、热处理、充氢、腐蚀、辐照和测试条件未改变。
- [ ] 温度、应变率、载荷比、频率、循环周次和环境未改变。
- [ ] 变量、希腊字母、上下标、公式、正负号和不等号未改变。
- [ ] 图表编号、样品名、条件名和引文编号未改变。
- [ ] 引文支撑命题和适用范围未漂移。
- [ ] 没有新增原文未提供的事实、数据、文献、机制或应用结论。
- [ ] 没有删除独立且有科学意义的信息。

## 2. 主张—证据

- [ ] 每项主张已归入 L0–L7 证据等级。
- [ ] 直接观察、差异、关联、贡献、因果和控制机制保持区分。
- [ ] 每个 induces、leads to、results in、controls、governs 都能映射到原文证据。
- [ ] controlled、governed、dominated 已处理主要替代解释。
- [ ] may、suggest、consistent with 等不确定性未被提高。
- [ ] qualitative difference 未被改写为 statistical significance。
- [ ] record、highest、unprecedented 有明确比较范围和条件。
- [ ] 机制推广写明必要条件和边界。
- [ ] enables、achieves、solves、overcomes 等设计动词具有设计动作—中间状态—结果的证据闭合。

## 3. 比较与性能

- [ ] 每个比较有对象、参数、参照状态和测试条件。
- [ ] 文献性能比较核对加载、温度、应变率、试样和寿命定义。
- [ ] 性能值带定义、单位和条件。
- [ ] P1 和 P2 的来源分别建立。
- [ ] 通常性能代价被抑制的过程得到解释或明确证据缺口。
- [ ] 多个同步变化的组织变量未被强行归因于单一原因。
- [ ] 性能图中的数据口径一致，或限制已说明。
- [ ] 工业规模、低成本、可制造性或临床适用性有原文证据。

## 4. Results

- [ ] 初始状态和比较基准先建立。
- [ ] 每段回答一个主要问题。
- [ ] 直接结果先于局部结论。
- [ ] 定量关系靠近对应图表。
- [ ] Results 中的因果判断由当前实验或数据直接支持。
- [ ] 本文新增计算输出作为结果报告，解释强度受限。
- [ ] Results 停在单项证据可直接支持的最强局部结论。
- [ ] 没有在 Results 中大段展开文献争论和跨体系推广。

## 5. Discussion

- [ ] Discussion 选择关键结果，没有逐图复述。
- [ ] 多尺度、多方法证据得到整合。
- [ ] 机制链中每个主要箭头得到解释或标记缺口。
- [ ] 定量模型、能量、几何、强化或速率分析与结果对应。
- [ ] 替代解释只在原文提出或真实证据冲突时讨论。
- [ ] 组织—变形—损伤—性能连接具有中间证据。
- [ ] 适用范围包含材料、组织、温度、应变率、环境或尺度。
- [ ] Discussion 没有首次引入决定摘要主张的新机制分支。

## 6. Results–Discussion 归属

- [ ] 只看当前图表可核查的内容留在 Results。
- [ ] 需要联合多图、模型或文献的内容进入 Discussion。
- [ ] 合并章节内部保持“证据—局部判断—综合解释”的顺序。
- [ ] 重复数值已压缩，关键证据未被讨论段替代。
- [ ] 当前归属调整未改变引文范围和段落命题。

## 7. 全文主线

- [ ] 已确定一句核心科学问题。
- [ ] 已确定一个主论文类型和必要次要模块。
- [ ] 主线中的每个环节能映射到原文。
- [ ] 并列观察未被生成因果链。
- [ ] 不同样品快照未被自动写成连续动力学。
- [ ] 题目、摘要、Introduction 末段、Results、Discussion 和 Conclusion 采用同一主张集合。
- [ ] 摘要发现或设计顺序与正文证明顺序一致。
- [ ] Introduction 末段承诺的问题均由正文回答。
- [ ] Conclusion 没有新增数据、机制或推广。

## 8. Introduction 专用（处理引言时）

### 8.1 最高层贡献与八项变量

- [ ] 最高层贡献能够写成“在条件 `C` 下，`X` 通过 `M` 改变 `Y`”。
- [ ] `Y` 明确为本文最终解释、调节或实现的结果、现象或能力。
- [ ] `A` 明确为当前最接近的公认解释、控制因素或设计策略。
- [ ] `C` 明确到具体相、温度、尺度、成分、演化阶段、服役条件或工程约束。
- [ ] `B` 明确为一个可被本文实验、计算或受控比较回答的关系。
- [ ] `X` 是本文发现或操控的关键变量、状态、组织或路径。
- [ ] `M` 说明 `X` 怎样连接到 `Y`，没有用方法清单代替中间过程。
- [ ] `E1–E3` 分别支持 `X`、`X → M` 和 `M → Y`。
- [ ] `G` 说明新增的解释、预测、调控或实施能力，并限定适用边界。
- [ ] 无法从现有材料确认的变量已列入作者确认项。

### 8.2 主路由与精确缺口

- [ ] 已判定发现导向或需求与性能导向，并能够说明选择依据。
- [ ] 混合论文已经确定首要问题，机制和性能分别位于主线、解释层或后果层。
- [ ] 精确缺口属于预期冲突、机制路径缺失、定量归因缺失或工程实现缺失中的至少一类。
- [ ] 正常预期、已知初态/终态或现有设计原理已建立。
- [ ] 已有研究已经回答到哪里得到明确说明。
- [ ] 已有研究停在什么具体步骤得到明确说明。
- [ ] 停下的原因、方法边界或工程约束得到明确说明。
- [ ] 精确缺口与最高层贡献处于同一逻辑层级。
- [ ] 新机制对应具体机制步骤缺失，新定量关系对应贡献大小、符号或耦合项缺失，新设计能力对应明确约束。
- [ ] 没有以 `few studies have investigated`、`limited attention`、`remains unclear` 或 `further studies are needed` 独立承担核心缺口。
- [ ] 替换检验通过：将末段替换为同领域另一篇论文时，前文不能仍然完全适用。

### 8.3 文献与最近邻对照

- [ ] 文献分别承担重要性、当前共识、最近前沿和精确缺口中的明确功能。
- [ ] 文献没有按年份、作者或表征方法逐篇罗列。
- [ ] 已选择与本文差异最小的最近邻体系、相、温区、尺度或实现条件作为对照。
- [ ] 最近邻对照能够把问题压缩到一个或少数关键变量。
- [ ] 每组引文仍紧邻其实际支撑的命题。
- [ ] 引文移动没有扩大支撑范围或提高结论强度。
- [ ] 只观察形貌、位置或关联的前人工作没有被改写为已经建立形核、演化或控制机制。
- [ ] first、only、never reported、unprecedented 和 to the best of our knowledge 具有明确检索依据。
- [ ] 用户未要求检索时，没有新增原文缺失的文献。

### 8.4 方法、段落与引言末段

- [ ] 每一种主要方法对应一个精确缺失的可观测量或可控变量。
- [ ] 方法只在缺口之后出现，没有以仪器清单代替研究问题。
- [ ] 已选择三段式、四段式或原有段数，并能够说明段落功能。
- [ ] 第一段只建立与 `Y` 直接相关的价值和必要共识，没有通用背景堆叠。
- [ ] 中间段从最近邻研究推进到边界、方法限制和 `B`。
- [ ] 每段只承担一个主要推进任务，段末形成下一问题。
- [ ] 每句主要承担重要性、共识、最近前沿、边界、缺口、方法限制或本文回答中的一个功能。
- [ ] Introduction 末段按照研究对象/干预 → `X` → `M` → `Y` → `E` → `G` 展开。
- [ ] Introduction 末段没有完整实验步骤、仪器清单、全部组织尺寸或全部性能数字。
- [ ] Introduction 末段的结果和证据顺序与正文一致。
- [ ] 异常型、机制路径型、定量归因型或设计实现型的首图任务与引言承诺一致。
- [ ] 末句返回开篇的 `Y`，并给出受证据约束的 `G`。

## 9. 摘要模式路由（处理摘要时）

- [ ] 已选择标准功能型、发现导向单链、设计/解决导向链或自动模式。
- [ ] 自动模式能够说明选择理由。
- [ ] 删除性能数字测试和删除机制测试已经执行。
- [ ] 核心贡献被判定为增加知识、增加能力，或需要标准功能型。
- [ ] 存在独立第二主线时没有强行压成单链。
- [ ] 目标期刊和篇幅与所选模式兼容。

## 10. 发现导向单链（启用时）

- [ ] 已确认全文可以提取一条主要科学关系。
- [ ] S1 只交代一项研究价值，没有通用背景堆叠。
- [ ] S2 同时交代已知边界和精确知识缺口。
- [ ] S3 属于本文新增认识，并能统领摘要后半的大部分证据。
- [ ] S3 只有一个主要谓语，没有方法、数值、完整工艺、组织清单和多组 benchmark。
- [ ] S3 的动词强度与时序、受控比较、中间变量和独立证据一致。
- [ ] S4 点名机制解析深度，没有退化为 `Using X, we investigated Y`。
- [ ] S3 之后每个独立句均提供本文新增信息。
- [ ] 领域常识、正常载荷分配或传统析出行为只作为必要基准嵌入新发现句。
- [ ] 每一句回答上一句产生的问题，删除任一句都会使某个证据箭头或必要限定断裂。
- [ ] 显微观察已凝练为“直接证据—上位机制—物理后果”，且没有越过证据上限。
- [ ] 倒数第二句具有明确物理落点。
- [ ] 最后一句写明具体科学认识和适用边界。
- [ ] 没有复制标定论文的可识别词句、具体机制或数据结构。

## 11. 设计/解决导向链（启用时）

- [ ] S1 定义目标能力或性能组合，未堆叠无关应用背景。
- [ ] S2 指出具体能力缺口，并在原文支持时说明物理瓶颈。
- [ ] S3 采用一个可控设计变量和一个目标能力，主干清楚。
- [ ] S3 没有完整工艺、多个数值、组织清单和宽泛应用愿景。
- [ ] S4 说明设计怎样建立关键中间变量或目标组织，没有退化为工艺步骤清单。
- [ ] 解决链已经闭合：需求 → 瓶颈 → 设计 → 中间变量 → 组织/状态 → 定量性能。
- [ ] 解释链已经闭合：组织/状态 → P1 → P2/代价抑制 → 综合能力。
- [ ] 组织形成机制和性能实现机制保持区分。
- [ ] P1 和 P2 没有被同一个宽泛机制笼统解释。
- [ ] 综合指标已拆解并重新汇合，例如 `εf = σf/E`。
- [ ] 性能句包含指标、数值、条件、对照和提升幅度。
- [ ] benchmark 的材料状态、几何、温度、应变率、寿命或加载条件可比。
- [ ] 规模化、低成本和工业实施性有实际证据。
- [ ] 倒数第二句落到具体设计或物理结果，例如 sustained hardening、delayed damage 或 limited penalty。
- [ ] 最后一句写出具体可控关系、目标能力和适用边界。
- [ ] 机制证据不足时降低机制动词，没有为了设计完整性补写中间过程。
- [ ] 已检查是否存在更强的发现导向上游关系，并记录路由理由。

## 12. 图序和段落

- [ ] 每幅主图承担一个主要证明任务。
- [ ] 图序可以复述论文的证明顺序。
- [ ] 图按科学问题组织，没有简单按仪器堆叠。
- [ ] 每段有明确主题句、证据和信息落点。
- [ ] 段末局部结论或下一问题自然衔接。
- [ ] 次要结果能够对应主线中的前提、箭头或边界。

## 13. 句法与语言

- [ ] 每句有明确主语和核心谓语。
- [ ] 每句只有一个主要命题。
- [ ] 句首承接已知信息，句末承载新结果或结论。
- [ ] 修饰语靠近被修饰对象。
- [ ] this、which、it 等指代唯一。
- [ ] 平行项目保持同一语法层级。
- [ ] 括号没有承载关键证据或核心逻辑。
- [ ] 术语、相名称、指标和缩写全文一致。
- [ ] 拼写体系、时态和语态一致。
- [ ] 删除无信息增量提示语、宣传性评价和重复结论。
- [ ] 没有为词汇变化替换准确术语。
- [ ] 没有复刻范文的可识别词句或具体机制结构。

## 14. 领域安全门

### 14.1 相变与析出

- [ ] 初始状态和目标相存在性明确。
- [ ] 快照与原位动力学区分。
- [ ] 形貌、晶体学、成分和结构证据分别陈述。
- [ ] DFT 未被写成实际动力学的直接证明。

### 14.2 同步辐射与变形

- [ ] 晶格应变的晶面族、方向和判据明确。
- [ ] 峰宽未未经分析直接等同于位错密度。
- [ ] 峰强变化未单独证明相变。
- [ ] 载荷转移解释核查相分数、织构、残余应力和弹性常数。
- [ ] 体平均结果与局部证据尺度区分。

### 14.3 疲劳与断裂

- [ ] ΔK、Kmax、R、裂纹尺寸、频率和环境明确。
- [ ] 裂纹萌生、短裂纹、长裂纹和最终失稳分开。
- [ ] 断口未单独指定完整裂纹机制。

### 14.4 氢脆

- [ ] 充氢方式、氢含量、等待时间、温度和应变率明确。
- [ ] 总氢、可扩散氢和陷获氢未混用。
- [ ] 断口和延性下降未单独识别 HELP、HEDE 或氢化物。
- [ ] 强机制结论有时间、空间和独立中间证据。

### 14.5 计算与模型

- [ ] 假设、边界、参数和验证明确。
- [ ] 拟合、解释和预测区分。
- [ ] 与实验一致未被写成唯一机制证明。
- [ ] 敏感性和适用范围得到说明。

## 15. 期刊适配与投稿材料（启用时）

- [ ] 期刊家族判定正确，长度、图数和摘要体裁符合目标家族。
- [ ] 摘要受众层次与家族匹配。
- [ ] Introduction 的段数、背景宽度和末段密度与目标体裁匹配。
- [ ] 压缩只移动或建议移入补充材料，未删除比较条件、误差和测试条件。
- [ ] 体裁适配未改变任何数据、条件、术语和结论强度。
- [ ] Highlights 3–5 条且每条 ≤85 字符，字符数已逐条报告。
- [ ] 一句话总结 ≤125 字符，字符数已报告。
- [ ] Cover Letter 未复制摘要，主张强度与正文一致。
- [ ] 图形摘要设计稿的机制示意不超过正文证据等级。
- [ ] 投稿材料中每个主张可在正文定位。
- [ ] 优先权词均有正文比较口径支持。

## 16. 作者确认项

- [ ] 数值、单位、图号或变量冲突已列出。
- [ ] 缺失比较基准、测试条件或材料状态已列出。
- [ ] 指代和术语歧义已列出。
- [ ] 机制中间环节缺失已列出。
- [ ] 设计动作—中间变量—目标组织的断链已列出。
- [ ] 文献比较不可比条件已列出。
- [ ] 快照被误当连续过程的问题已列出。
- [ ] Results–Discussion 归属无法可靠判断的内容已列出。
- [ ] 摘要核心发现或核心解决方案无法唯一提取的问题已列出。
- [ ] Introduction 最高层贡献无法由现有题目、摘要、Results、Discussion 或 Conclusion 确认的问题已列出。
- [ ] Introduction 精确缺口缺少引文支撑、最近邻对照或方法边界的问题已列出。
- [ ] Introduction 中 `Y、A、C、B、X、M、E、G` 的缺失项及其影响已列出。
- [ ] 需要新增文献检索、实验、模型或统计才能解决的问题已列出。
