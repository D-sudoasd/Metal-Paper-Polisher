# 精修与科学论证质量核查表（v4）

## 1. 科学信息锁定

- [ ] 数值、单位、误差、有效数字和统计量与原文一致。
- [ ] 材料牌号、成分、相名称、组织状态和取向未改变。
- [ ] 工艺、热处理、充氢、腐蚀、辐照和测试条件未改变。
- [ ] 温度、应变率、载荷比、频率、循环周次和环境未改变。
- [ ] 变量、希腊字母、上下标、公式、正负号和不等号未改变。
- [ ] 图表编号、样品名、条件名和引文编号未改变。
- [ ] 引文支撑命题和适用范围未漂移。
- [ ] 没有新增原文未提供的事实、数据、文献、机制或应用结论。
- [ ] 没有删除独立且有科学意义的信息。

## 2. 主张—证据

- [ ] 每项主张已归入 L0–L7 证据等级。
- [ ] 直接观察、差异、关联、贡献、因果和控制机制保持区分。
- [ ] 每个 induces、leads to、results in、controls、governs 都能映射到原文证据。
- [ ] controlled、governed、dominated 已处理主要替代解释。
- [ ] may、suggest、consistent with 等不确定性未被提高。
- [ ] qualitative difference 未被改写为 statistical significance。
- [ ] record、highest、unprecedented 有明确比较范围和条件。
- [ ] 机制推广写明必要条件和边界。

## 3. 比较与性能

- [ ] 每个比较有对象、参数、参照状态和测试条件。
- [ ] 文献性能比较核对加载、温度、应变率、试样和寿命定义。
- [ ] 性能值带定义、单位和条件。
- [ ] P1 和 P2 的来源分别建立。
- [ ] 通常性能代价被抑制的过程得到解释或明确证据缺口。
- [ ] 多个同步变化的组织变量未被强行归因于单一原因。
- [ ] 性能图中的数据口径一致，或限制已说明。

## 4. Results

- [ ] 初始状态和比较基准先建立。
- [ ] 每段回答一个主要问题。
- [ ] 直接结果先于局部结论。
- [ ] 定量关系靠近对应图表。
- [ ] Results 中的因果判断由当前实验或数据直接支持。
- [ ] 本文新增计算输出作为结果报告，解释强度受限。
- [ ] Results 停在单项证据可直接支持的最强局部结论。
- [ ] 没有在 Results 中大段展开文献争论和跨体系推广。

## 5. Discussion

- [ ] Discussion 选择关键结果，没有逐图复述。
- [ ] 多尺度、多方法证据得到整合。
- [ ] 机制链中每个主要箭头得到解释或标记缺口。
- [ ] 定量模型、能量、几何、强化或速率分析与结果对应。
- [ ] 替代解释只在原文提出或真实证据冲突时讨论。
- [ ] 组织—变形—损伤—性能连接具有中间证据。
- [ ] 适用范围包含材料、组织、温度、应变率、环境或尺度。
- [ ] Discussion 没有首次引入决定摘要主张的新机制分支。

## 6. Results–Discussion 归属

- [ ] 只看当前图表可核查的内容留在 Results。
- [ ] 需要联合多图、模型或文献的内容进入 Discussion。
- [ ] 合并章节内部保持“证据—局部判断—综合解释”的顺序。
- [ ] 重复数值已压缩，关键证据未被讨论段替代。
- [ ] 当前归属调整未改变引文范围和段落命题。

## 7. 全文主线

- [ ] 已确定一句核心科学问题。
- [ ] 已确定一个主论文类型和必要次要模块。
- [ ] 主线中的每个环节能映射到原文。
- [ ] 并列观察未被生成因果链。
- [ ] 不同样品快照未被自动写成连续动力学。
- [ ] 题目、摘要、引言末段、Results、Discussion 和 Conclusion 采用同一主张集合。
- [ ] 摘要发现顺序与正文证明顺序一致。
- [ ] Conclusion 没有新增数据、机制或推广。

## 8. 图序和段落

- [ ] 每幅主图承担一个主要证明任务。
- [ ] 图序可以复述论文的证明顺序。
- [ ] 图按科学问题组织，没有简单按仪器堆叠。
- [ ] 每段有明确主题句、证据和信息落点。
- [ ] 段末局部结论或下一问题自然衔接。
- [ ] 次要结果能够对应主线中的前提、箭头或边界。

## 9. 句法与语言

- [ ] 每句有明确主语和核心谓语。
- [ ] 每句只有一个主要命题。
- [ ] 句首承接已知信息，句末承载新结果或结论。
- [ ] 修饰语靠近被修饰对象。
- [ ] this、which、it 等指代唯一。
- [ ] 平行项目保持同一语法层级。
- [ ] 括号没有承载关键证据或核心逻辑。
- [ ] 术语、相名称、指标和缩写全文一致。
- [ ] 拼写体系、时态和语态一致。
- [ ] 删除无信息增量提示语、宣传性评价和重复结论。
- [ ] 没有为词汇变化替换准确术语。
- [ ] 没有复刻范文的可识别词句或具体机制结构。

## 10. 领域安全门

### 10.1 相变与析出

- [ ] 初始状态和目标相存在性明确。
- [ ] 快照与原位动力学区分。
- [ ] 形貌、晶体学、成分和结构证据分别陈述。
- [ ] DFT 未被写成实际动力学的直接证明。

### 10.2 同步辐射与变形

- [ ] 晶格应变的晶面族、方向和判据明确。
- [ ] 峰宽未未经分析直接等同于位错密度。
- [ ] 峰强变化未单独证明相变。
- [ ] 载荷转移解释核查相分数、织构、残余应力和弹性常数。
- [ ] 体平均结果与局部证据尺度区分。

### 10.3 疲劳与断裂

- [ ] ΔK、Kmax、R、裂纹尺寸、频率和环境明确。
- [ ] 裂纹萌生、短裂纹、长裂纹和最终失稳分开。
- [ ] 断口未单独指定完整裂纹机制。

### 10.4 氢脆

- [ ] 充氢方式、氢含量、等待时间、温度和应变率明确。
- [ ] 总氢、可扩散氢和陷获氢未混用。
- [ ] 断口和延性下降未单独识别 HELP、HEDE 或氢化物。
- [ ] 强机制结论有时间、空间和独立中间证据。

### 10.5 计算与模型

- [ ] 假设、边界、参数和验证明确。
- [ ] 拟合、解释和预测区分。
- [ ] 与实验一致未被写成唯一机制证明。
- [ ] 敏感性和适用范围得到说明。

## 11. 作者确认项

- [ ] 数值、单位、图号或变量冲突已列出。
- [ ] 缺失比较基准、测试条件或材料状态已列出。
- [ ] 指代和术语歧义已列出。
- [ ] 机制中间环节缺失已列出。
- [ ] 文献比较不可比条件已列出。
- [ ] 快照被误当连续过程的问题已列出。
- [ ] Results–Discussion 归属无法可靠判断的内容已列出。
- [ ] 需要新增实验、模型或统计才能解决的问题已列出。
