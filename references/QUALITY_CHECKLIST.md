# 精修质量核查表（v3）

## 科学信息

- [ ] 所有数值、单位、误差和显著性水平与原文一致。
- [ ] 材料牌号、成分、状态、取向、热处理和测试条件未改变。
- [ ] 变量、希腊字母、上下标、公式、正负号和不等号未改变。
- [ ] 图表编号、样品名称和引用编号未改变。
- [ ] 没有新增数据、事实、文献、机制或应用结论。
- [ ] 没有删除任何独立且有科学意义的信息。

## 证据与结论

- [ ] 观察、相关、解释、推测和因果结论保持原有层级。
- [ ] 因果动词与证据强度一致。
- [ ] significant 具有统计依据，或已改为中性、可验证表达。
- [ ] superior、effective、excellent 等评价词具有指标和比较基准。
- [ ] 机制解释与对应证据相邻。
- [ ] 结论没有超出正文或原段落展示的证据。
- [ ] 精修稿中的每一处 induces / leads to / results in / 从而 / 导致 都能映射回原文的连接关系或原文给出的时间–状态序列。

## 比较与适用范围

- [ ] 每个比较均有明确对象和参数。
- [ ] 参照状态、驱动力、温度、载荷比、应变率或裂纹尺寸已说明。
- [ ] 比较条件靠近比较对象。
- [ ] 结论边界和材料范围清楚。

## 句法与段落

- [ ] 每句具有明确主语和核心谓语。
- [ ] 每句只有一个主要命题。
- [ ] 修饰语靠近被修饰对象。
- [ ] 代词和 this/which/it 的指代唯一。
- [ ] 平行项目保持相同语法结构。
- [ ] 括号未承载关键证据或主要逻辑关系。
- [ ] 每段围绕一个主要讨论对象。
- [ ] 段落顺序符合所在论文部分的功能。

## 全文架构（架构干预未关闭时）

- [ ] 已判定论文类型（M/F/P/C/R），未把错误类型的故事形态套到本文。
- [ ] 主线是从原文提取的，不是从并列观察生成的。
- [ ] 若原文有链：摘要已用压缩形式给出该链；引言末段给出链而不给出数据表。
- [ ] 若原文无链：精修稿未发明链；缺失环节已进入作者确认项。
- [ ] 机制类结果按过程阶段推进，而不是按技术手段分列（在用户允许的重排范围内）。
- [ ] 进度条指标均在原文多个状态中出现；没有补写未测量的量。
- [ ] 新观察与上一阶段的衔接不暗示原文没有的连续性。
- [ ] 计算/DFT 紧跟它所解释的观察，且原文确实用该计算解释该观察。
- [ ] 讨论未开辟摘要未宣布的新情节；对比、定量、迁移三项只使用原文已有内容。
- [ ] 同一结构指标、取向关系写法和阶段名称全文一致。

## 语言与格式

- [ ] 专业术语和缩写前后一致。
- [ ] 英式或美式拼写体系一致。
- [ ] 时态和语态符合论文部分功能。
- [ ] 删除无信息增量的提示语和重复结论。
- [ ] 没有为词汇变化而替换准确术语。
- [ ] 没有因风格化而无依据扩写。
- [ ] 没有复刻任何标定论文的可识别词句、OR 表述或口号。

## 作者确认项

- [ ] 数值、单位或图表冲突已列出。
- [ ] 缺失的比较基准或实验条件已列出。
- [ ] 不能唯一确定的术语或指代已列出。
- [ ] 证据不足的机制解释已列出。
- [ ] 引用范围不清的问题已列出。
- [ ] 缺失、断裂或仅并列的因果环节已列出（未在正文补写）。
- [ ] 被当作连续动力学轨迹、但原文未声明相继关系的状态已列出。
