# 全文逻辑架构规则（v3）

本文件把高水平机制论文中可迁移的**故事组织方式**写成可执行规则。标定样本是实验–机制类论文的抽象结构（对象收束、因果主线提前、结果按过程轨迹推进、讨论升维），**不是**任何单篇的词句、取向关系、具体机制或图表安排。

所有架构操作服从 SKILL.md 中的科学内容保护：只能显式化、重排、衔接原文已经建立的逻辑关系，不得发明因果链、不得新增机制环节、不得补写原文未追踪的结构指标。

加载时机：论文类型为机制/析出/相变，或用户要求逻辑优化、结构重组、深度学术重写时。疲劳断裂类仍以对照驱动力架构为主，见 `PAPER_TYPE_ROUTING.md`。

---

## 0. 安全门（先于一切架构操作）

1. **因果链只能提取，不能生成。**  
   只有原文已经用 because / therefore / leading to / induces / results in / 导致 / 诱导 / 从而 / 因此 等关系，或用时间–状态序列把 A→B→C 连起来时，才可以把这条链作为主线。若原文只是并列报告 A、B、C，不得把它们改写成必然因果序列。

2. **进度条只能复用，不能发明。**  
   贯穿结果的定量指标必须是原文已经在多个状态下给出的量（晶格参数、shuffle 幅度、取向差、厚度、密度、角度等）。原文只出现一次的量，不得提升为全文进度条。

3. **提前陈述只能压缩，不能预支未写内容。**  
   摘要和引言末段可以提前给出全文因果链，当且仅当该链的每个环节都能在后文找到对应证据。不得把讨论里才首次出现、且原文未在前面承诺的新情节写进摘要。

4. **衔接语不是新科学。**  
   允许增加 at this stage / relative to / further / inherits / remains continuous with / becomes closer to 等组织性衔接，前提是不改变观察内容、不提高确定性、不暗示原文没有的连续性。

5. **架构诊断不等于补全。**  
   发现原文缺某个常见环节时，写入“需作者确认的问题”，不在精修稿中补写该环节。

## 1. 规则一：动机金字塔（Hierarchical Motivation Pyramid）

### 操作定义

引言前 1–1.5 页（或对应中文篇幅）按收束漏斗组织，每一层只回答一个问题：

| 层级 | 功能 | 只使用原文已有的 |
|---|---|---|
| L1 应用/性能重要性 | 为什么这个体系值得研究 | 原文给出的应用、性能、服役条件 |
| L2 加工或相组成现实 | 实际材料里发生了什么 | 热处理、增材、淬火、相组成 |
| L3 具体对象 | 本文真正处理的相、界面、裂纹或过程 | 具体相、马氏体、析出相、裂纹类型 |
| L4 精确缺口 | 缺的是机制、尺度联系、条件还是证据类型 | 原文对先前工作的具体批评 |
| L5 先前工作失败的原因 | 分辨率、化学敏感性、形貌 vs 机制、缺少原位等 | 原文已经指出的方法限制 |
| L6 本文将回答的机制问题 | 一句话点名问题，不在此处展开证据 | 原文的研究目标 |

### 允许的操作

- 把散落在引言中的“重要性—加工—对象—缺口—方法限制—目标”按上表重排。
- 把空洞的 remains poorly understood 改成原文已经说出的具体缺口（缺何种证据、何种尺度、何种机制环节）。
- 让 L5 自然引出方法选择，但不新增方法优点。

### 禁止

- 补写原文没有的应用场景或工程意义。
- 把“先前研究较少”写成对具体工作的方法批评，若原文没有该方法批评。
- 在金字塔末尾提前给出后文没有的机制结论。

### 与旧规则的关系

旧技能 9.2“已有认识—未解决问题—影响—目标”仍然正确，但是一层功能清单。本规则把它收成**有层级的漏斗**，并要求缺口必须具体到证据类型。

## 2. 规则二：完整因果链提前陈述（State the Spine Early）

### 操作定义

在摘要中、以及引言最后一段，用压缩形式给出全文因果链。读者带着“目的地”读 Results，而不是边读边猜故事。

机制论文的摘要骨架（仅当原文已有这些环节时）：

1. 对象 + 已知事实 + **具体机制缺口**
2. 本文主张（聚类/偏聚/缺陷/界面如何诱导下一事件）——必须是原文已有主张
3. 方法（只列为回答该机制所必需的手段）
4. 发现按因果顺序，而不是按图表编号顺序
5. 生长/演化如何改变变体、取向关系或最终组织（若原文有）
6. 适用范围（仅原文已给出时）

引言末段重复同一条链，用将来时或研究目标口气，不抢写定量细节。

### 允许的操作

- 从结果和讨论中提取作者已经建立的 A→B→C，压缩进摘要/引言末段。
- 让摘要中的发现顺序与后文阶段顺序一致。
- 删除摘要里与主线无关的次要观察（若用户允许删减且该观察在正文仍保留）。默认不删独立科学信息；若摘要过长，优先压缩方法细节而不是砍掉因果环节。

### 禁止

- 把结果里尚未被作者连接的观察写成一条新机制故事。
- 在摘要中使用 for the first time / never been reported，除非原文已有同等强度的优先权声明。
- 让引言末段变成第二份摘要，重复全部定量结果。引言末段给链，不给数据表。

### 检验

读完摘要后，应能用一句话复述主线。该句的每个动词都能在结果或讨论中找到出处。

## 3. 规则三：结果按过程轨迹推进，并用少数定量指标做进度条

### 操作定义

机制/动力学类结果不按“技术手段分节”（先 TEM 再 XRD 再 DFT），而按现象自身的时间或状态顺序：

初始态 → 早期局域变化 → 形核 → 生长/取向演化 → 终态

在原文已经多次给出的定量标记中，选出 2–4 个作为进度条，每个阶段都回写这些标记的当前值或相对变化。读者因此感到在跟踪同一过程，而不是在看互不相关的快照。

### 进度条候选（仅使用原文已有者）

- 结构偏离度：shuffle 幅度、轴比、晶格参数、峰位移
- 几何量：平面夹角、取向差、变体数量、板条厚度/长度
- 化学量：溶质富集、团簇尺寸、成分幅值
- 缺陷量：位错密度、层错、孪晶分数

同一标记在各阶段尽量占据句子中的相同句法位置，例如：  
`the y value increased from 0.118 to 0.127`  
后续阶段继续写 y value，而不是改成“shuffle 更明显”这种不可比的定性替换。

### 允许的操作

- 按时效/应变/温度/循环周次重排段内句序。
- 把同一指标从段末提到与阶段判定相邻的位置。
- 用相对前一状态的语言连接，不新增数据。

### 禁止

- 为了进度条而补测或补写原文没有的量。
- 把 DFT、力学性能或无关表征插入轨迹，打断过程叙事（它们应作为对该阶段的即时解释，或放到讨论）。
- 把不同样品、不同放大倍数的观察写成连续动力学，若原文未声明它们构成同一过程的相继阶段。

## 4. 规则四：继承原则（Inheritance）

### 操作定义

每一个新观察必须显式承接上一阶段，使叙事不跳跃。

### 允许使用的组织性衔接（不改变科学内容）

- 状态衔接：At this stage; After ageing at …; Relative to the as-quenched condition
- 程度衔接：further modified; becomes closer to; remains; no longer retains
- 连续性衔接：crystallographic continuity; inferred to have formed via growth of; the same orientation relationship, now rotated by …
- 指标回指：the y value, previously 0.118, increased to …

### 句级模板（用原文内容填空）

- `[新结构]` is locally derived from `[上一阶段结构]`, as indicated by `[原文已有的连续性证据]`。
- Compared with `[上一状态]`, `[同一指标]` changed from X to Y, while `[未变的特征]` remained.

### 禁止

- 在原文没有连续性证据时，使用 inferred to grow from / inherits。
- 用衔接语把时间上相邻但机制上未连接的现象写成母子关系。
- 为了“不断裂”而合并作者明确分开的两种机制路径。

## 5. 规则五：理论紧跟它所解释的观察（Theory as Immediate Why）

### 操作定义

DFT、弹性计算、几何匹配、热力学估算不是平行的“模拟章节口吻”，而是对刚刚给出的实验观察回答“为什么”。

典型配对：

| 实验刚展示的 | 理论立即解释的 |
|---|---|
| 溶质团簇/偏聚位置 | 结合能、占据偏好 |
| 局域点阵畸变 | 弛豫后的结构单元如何接近新相 |
| 非常规取向关系 | 点阵对应和 shuffle 路径 |
| 生长中的旋转或变体倍增 | 共格匹配所需的几何转角 |
| 裂纹扩展速率转折 | 屏蔽或闭合的定量条件 |

### 允许的操作

- 在用户允许跨段重排时，把“先全部实验、后全部计算”改成“观察–解释”配对，前提是原文已经把该计算用于解释该观察。
- 在段内把结合能/转角计算结果移到对应图像描述之后。
- 保留独立的计算方法段在 Methods 中；Results/Discussion 中只出现解释功能。

### 禁止

- 把作者故意分开的系统计算（例如完整结合能扫描）拆碎到每个 TEM 图下面，若这会破坏计算的完整性或改变其命题范围。
- 为解释而补做或补写原文没有的计算。
- 用模拟口吻（The calculation shows that the mechanism is…）替代原文的证据强度词。

## 6. 规则六：讨论把观察升维为可迁移原则（Contrast–Quantify–Transfer）

### 操作定义

讨论不是结果复述。在原文已经具备相应内容时，按三次动作组织：

**(a) 对比替代解释**  
明确本文机制与原文提到的先前解释（spinodal、位错诱导、界面形核、经典 Burgers 切变等）在哪一步分叉。对比必须使用原文已给出的区分判据（有无结构畸变、是否需要位错、成分调制是否伴随原子列位移等）。

**(b) 给出定量几何或能量依据**  
将关键“奇怪现象”（非常规 OR、变体数目变化、临界尺寸）还原为原文已有的公式、转角、错配、结合能或判据。让读者感到这是推出来的，而不是事后附加的。

**(c) 检验可迁移性**  
仅当原文已对其它溶质、合金、裂纹体系或加载条件做了对比或计算时，把它们集中放在讨论后部，说明主线可迁移的边界。

### 允许的操作

- 重排讨论段顺序为：待解释现象 → 直接证据 → 与替代解释的分叉点 → 定量依据 → 可迁移性 → 适用边界。
- 删除重复的结果复述，改为回指“as shown in Fig. X / at the nucleation stage”。
- 保留原文已提出的替代解释；不删除也不新增争议。

### 禁止

- 引入原文未讨论的替代机制来“显得全面”。
- 把结合能或转角计算从结果中复制一遍充作新讨论。
- 把可迁移性写成对未研究体系的断言。

## 7. 规则七：视觉与术语一致性（降低认知切换）

### 操作定义

全文使用同一套结构描述语言，让主线在文字中反复可见。

### 具体操作

- **取向关系、晶带轴、界面步骤** 的书写格式全文统一；若 OR 随过程演化，用“同一 OR 的演化表述”，不要每段换一套符号。
- **同一结构指标** 不要在结果里叫 y value、在讨论里改叫 shuffle magnitude、在结论里又叫 orthorhombicity，除非第一次出现时建立对应关系。
- **阶段命名** 稳定：as-quenched / early clustering / embryo / growth with rotation / fully decomposed（名称必须能在原文找到对应状态；可做语言统一，不可做科学重新划分）。
- **图注** 独立可读，但仍使用与正文相同的指标名和阶段名。
- 不要求作者增补示意图；若原文已有机制示意图，图注应按“初始格子 → 局域畸变 → 新相胚胎 → 旋转/终态 OR”的顺序描述，且不添加图中未见的步骤。

### 禁止

- 为一致性而统一原文有意区分的两种结构（例如 α′ 与 α″，长裂纹与短裂纹）。
- 改写符号体系若作者已在方法中定义且后文依赖该定义。

## 8. 摘要 / 引言 / 结果 / 讨论 的架构核对清单

### 摘要

- [ ] 缺口是具体机制问题，不是“研究较少”
- [ ] 全文因果链已以压缩形式出现
- [ ] 发现顺序 = 后文过程顺序
- [ ] 每个因果动词能在正文定位
- [ ] 没有预支正文未支持的推广

### 引言

- [ ] 漏斗收束，而不是文献堆砌
- [ ] 缺口具体到证据类型或方法限制
- [ ] 末段给出将要证明的链，而非全部数据
- [ ] 未把综述型 field–gap–scope 套到实验细节段

### 结果

- [ ] 按过程阶段而非技术手段推进（机制类）
- [ ] 2–4 个原文已有指标被重复追踪
- [ ] 新观察显式承接上一阶段
- [ ] 计算紧贴它所解释的观察
- [ ] 没有把解释升级为原文未支持的机制结论

### 讨论

- [ ] 不引入新情节
- [ ] 完成原文已有的对比 / 定量 / 迁移中的相应动作
- [ ] 与摘要主线闭合
- [ ] 替代解释仅限原文已提出者

## 9. 失败模式（必须避免）

| 失败 | 典型表现 | 正确处理 |
|---|---|---|
| 发明主线 | 把并列观察写成 A induces B induces C | 保持并列；在确认项中说明“原文未建立因果链” |
| 假进度条 | 补写原文没有的 y 值或角度 | 只用已出现的量 |
| 假继承 | 无连续性证据却写 grows from the embryo | 只用空间相邻、形貌相似等原文实际表述 |
| 架构套用错误类型 | 把析出轨迹套到疲劳裂纹扩展 | 先走论文类型路由 |
| 摘要剧透过量 | 引言末段变成第二摘要 | 链在引言，数据在结果 |
| 讨论开新篇 | 讨论首次提出摘要没有的机制分支 | 要么前移到摘要/引言（若原文本有），要么降为局部解释并核对是否越界 |
| 风格污染 | 复刻某篇论文的 OR 表述或口号 | 只吸收抽象结构 |
