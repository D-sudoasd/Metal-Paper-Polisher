# 全文科学叙事与论证架构（v5）

本文件处理全文层面的科学问题、主张、证据、图序和章节关系。所有重排受 `SKILL.md` 的科学内容保护规则约束。

## 0. 架构操作的安全门

### 0.1 主线只能提取

主线中的每一个箭头必须能映射到原文中的至少一种支持：

- 明确连接语；
- 受控变量对照；
- 原位时间顺序；
- 多状态演化序列；
- 中间变量测量；
- 模型与实验相互验证；
- 作者已经提出的机制解释。

原文只并列 A、B 和 C 时，保持并列。不得为获得流畅感写成 A→B→C。

### 0.2 组织性衔接不得改变科学含义

可以添加 at this stage、relative to the reference state、with further deformation、under the same loading condition 等衔接。衔接语不得暗示：

- 未证明的母子关系；
- 未说明的时间连续性；
- 未测量的中间态；
- 未排除替代解释的强因果。

### 0.3 证据依赖决定顺序

章节和段落按照读者接受结论所需的前提排序。后一个结论依赖前一个结论时，前者应先出现。独立证据可以并列，但需要明确各自服务于哪一主张。

### 0.4 不因范文补齐常见环节

高水平论文常有基准、演化、中间机制、定量验证和推广。原文缺少其中一项时，指出缺口，不补写内容。

## 1. 一句话核心问题

重写前用一句话确定全文问题。句式按类型选择：

### 1.1 机制型

> 在【材料和初始状态】中，【过程】如何由【先导事件】经【中间步骤】发展为【终态】？

### 1.2 性能型

> 【设计动作】通过改变哪一【组织或变形/损伤过程】，实现【性能组合】，并抑制通常的【性能代价】？

### 1.3 变形型

> 【成分或组织】如何改变【相/晶粒族】的屈服顺序、载荷分配和局部化，从而影响【宏观响应】？

### 1.4 环境损伤型

> 【环境或氢状态】主要改变损伤过程的哪一阶段，并通过哪些可验证中间过程导致【性能退化】？

一句话中包含两个独立主问题时，应选择主问题，另一问题作为支撑层或拆分为另一篇论文。

## 2. 主张层级

全文按四层组织：

1. **总问题**：论文最终回答什么；
2. **主要结论**：通常 2–5 项；
3. **证据组**：每项结论需要哪些图、表、计算或文献；
4. **单项结果**：具体测量、图像、数值和观察。

建立主张—证据表：

| 主要结论 | 直接结果 | 独立验证 | 解释或模型 | 适用条件 | 证据等级 |
|---|---|---|---|---|---|

没有证据组支撑的主要结论不得通过润色保留为强结论，应降级或列入作者确认项。

## 3. 跨部分一致性

### 3.1 题目

题目只包含全文真正建立的最高层主张。题目中的 mechanism、induced、controlled、record、unprecedented 等词需与正文证据一致。

### 3.2 摘要

摘要压缩主问题、设计或变量、关键结果、机制认识和边界。摘要中的每个主要动词都应在正文定位。

### 3.3 引言末段

引言末段承诺研究将回答什么、用什么证据路线回答。它可以压缩主线，不应重复全部数值。

### 3.4 Results

Results 逐步建立摘要主张所需的证据，不额外开辟无关主线。

### 3.5 Discussion

Discussion 解释 Results 已经建立的关键事实，闭合摘要中的机制或性能逻辑，检验边界。

### 3.6 Conclusion

Conclusion 按同一顺序回收主要结论。结论顺序与摘要发现顺序和 Results 的证明顺序保持对应。

## 4. 引言的收束逻辑

### 4.1 通用依赖顺序

1. 材料体系、应用或基础问题；
2. 具体组织、性能或失效过程；
3. 已有可确定认识；
4. 精确缺口；
5. 缺口产生的证据或方法原因；
6. 本文的变量、设计和证据路线；
7. 本文将建立的主张。

### 4.2 精确缺口的类型

缺口应具体到：

- 缺少初始状态；
- 缺少时间顺序；
- 缺少局部成分或结构证据；
- 缺少相间/晶粒间载荷分配；
- 缺少损伤形核前的原位证据；
- 缺少跨尺度连接；
- 缺少可比性能基准；
- 缺少机制区分判据；
- 缺少适用条件或不确定度。

“研究较少”只在原文具有可靠文献依据时保留。

## 5. Results 的证明顺序

### 5.1 基准优先

任何变化、形成、提高、降低、偏聚、相变、损伤和失效都需要参照：

- 初始材料状态；
- 对照成分或工艺；
- 未充氢状态；
- 加载前状态；
- 相同驱动力；
- 相同测试条件。

### 5.2 过程型顺序

机制、变形和损伤论文通常采用：

`初始状态 → 最早变化 → 中间态 → 后续演化 → 终态/失效 → 局部原因证据`

### 5.3 性能型顺序

性能论文通常采用：

`设计实现 → 组织定量 → 性能证明 → 变形/损伤过程 → 机制证据 → 定量分解`

性能值应在正文较早出现，读者随后理解其来源。

### 5.4 条件型顺序

疲劳、蠕变、腐蚀和模型论文可按：

`低驱动力/低温/低应力 → 转折区间 → 高驱动力/高温/高应力`

每个区间复用相同指标和比较口径。

## 6. 贯穿指标

选用原文在多个状态下已经报告的 2–4 个量，以降低认知切换。例如：

- 相分数、晶格参数、正交度、取向差、变体数；
- 析出尺寸、间距、数密度；
- 晶格应变、峰宽、局部应变、相级应力；
- 屈服强度、加工硬化率、均匀延伸、韧性；
- da/dN、ΔKth、闭合水平、裂纹长度；
- 氢含量、陷阱峰、裂纹形核应变；
- 蠕变速率、应力指数、活化能。

同一量全文使用同一术语和符号。没有多状态数据时，不强制设置贯穿指标。

## 7. 段落接力

每段完成两个动作：

1. 回答一个明确问题；
2. 留下下一段必须回答的问题。

段末常见功能：

- 给出受当前证据支持的局部结论；
- 指出当前结果不能解释的下一问题；
- 引出对应计算或局部表征；
- 从性能证明转入机制证据；
- 从裂纹形核转入裂纹扩展。

禁止为了衔接而写入新的科学前提。

## 8. 图序设计

### 8.1 一图一主要证明任务

每幅主图回答一个主要问题。多个面板可以分别提供：

- 直接观察；
- 定量统计；
- 对照；
- 局部放大；
- 模型验证。

一幅图承担三个相互独立结论时，应检查是否拆分或调整正文主张。

### 8.2 图序自检

只阅读图题，应能复述论文的证明顺序。例如：

1. 初始组织；
2. 关键变化；
3. 定量性能；
4. 原位变形或损伤；
5. 局部机制；
6. 模型或推广。

### 8.3 图与章节一致

图按科学问题归组，不按 TEM、XRD、EBSD、DFT 等工具分别堆叠。系统计算或完整方法验证可保持独立小节，前提是其科学命题完整。

## 9. 机制链的逐箭头核查

对每个 A→B 检查：

- A 是否先于 B；
- A 和 B 是否具有空间或结构连续性；
- 是否存在中间变量 C；
- 改变 A 是否改变 B；
- 是否有定量关系；
- 是否有能量、动力学、力学或晶体学依据；
- 主要替代解释是否被处理；
- 证据来自同一尺度还是跨尺度推断。

一个箭头缺证据时，保持 association、consistent with、suggests 等强度，并在诊断中明确缺口。

## 10. 性能链的双路径核查

性能论文至少建立两条路径：

### 10.1 性能收益路径

`组织/缺陷变化 → 变形或损伤阻力 → 性能 P1`

### 10.2 代价抑制路径

`组织/缺陷变化 → 应变硬化/协调变形/裂尖塑性/损伤离域 → 性能 P2 保留或提高`

若同一组织因素被用于解释相反性能，应说明其在不同尺度、阶段或机制中的不同作用。缺少第二条路径时，不能只用“synergistic”概括强塑、强韧或低模量—疲劳协同。

## 11. Discussion 的升维顺序

Discussion 可根据原文内容采用以下动作：

1. **选择核心结果**：不逐项复述所有图；
2. **连接证据**：整合显微、力学、原位和计算；
3. **解释中间过程**：回答局部因果箭头；
4. **定量检验**：模型、几何、能量、强化分解、速率关系；
5. **处理替代解释**：只处理原文提出或证据冲突真实存在者；
6. **跨尺度连接**：从原子/位错/界面到宏观性能；
7. **限定边界**：材料、组织、温度、应变率、环境和尺度；
8. **推广**：只在必要条件得到检查时进行。

讨论中的新图可以提供模型验证或综合分析，但不能成为摘要核心主张唯一的新证据。

## 12. 混杂变量检查

组织—性能论文常同时改变多个变量。至少检查：

- 晶粒或片层尺寸；
- 相分数；
- 织构；
- 残余应力；
- 位错密度；
- 析出物尺寸与间距；
- 孔隙、夹杂和表面状态；
- 试样几何和测试条件。

无法区分贡献时，使用 associated with、collectively contribute、cannot be isolated 等受限表述，不指定唯一原因。

## 13. 架构干预的权限边界

### 13.1 仅诊断

输出：

- 一句话核心问题；
- 主线环节；
- 埋没或倒置内容；
- Results–Discussion 归属；
- 图序问题；
- 缺失证据。

不移动文本。

### 13.2 段内重排

可调整句序，使证据先于局部结论、比较条件靠近结果、段落只回答一个问题。

### 13.3 跨段或跨小节重排

只有用户明确允许时执行。移动引文时保持支撑范围。跨小节移动计算或模型时，确认不破坏方法完整性和命题范围。

## 14. 常见失败模式

| 失败 | 表现 | 处理 |
|---|---|---|
| 主线生成 | 将并列观察写成因果链 | 保持并列并列出缺口 |
| 快照当动力学 | 不同试样被写成连续生长 | 限定为不同状态或位置 |
| 性能即机制 | 看到强度提高就指定强化机制 | 先报告性能，再核查独立证据 |
| 一种组织解释所有性能 | 同一句笼统解释强度和延性 | 分开建立性能路径 |
| Discussion 重复 Results | 大量复述数值和图 | 选择关键结果并整合解释 |
| Discussion 开新主线 | 核心机制首次在末尾出现 | 检查正文证据和摘要承诺 |
| 图按工具堆叠 | TEM、XRD、DFT 各成孤立章节 | 按科学问题重新归组 |
| 强因果过早 | 先写 governed，后补相关证据 | 降级措辞或补充确认项 |
| 文献性能不可比 | 不同 R、温度、寿命混为性能图 | 明确条件和比较限制 |
| 范文过拟合 | 套用某篇论文的具体阶段和句式 | 只保留抽象功能顺序 |

## 15. 全文核查表

### 题目与摘要

- [ ] 题目主张得到正文支持；
- [ ] 摘要的定量结果带条件；
- [ ] 摘要机制强度与正文一致；
- [ ] 摘要发现顺序与正文证明顺序一致。

### 引言

- [ ] 缺口具体到证据或中间变量；
- [ ] 方法选择由缺口自然引出；
- [ ] 引言末段承诺的每项任务均在正文完成。

### Results

- [ ] 初始状态和基准先建立；
- [ ] 每段一个问题；
- [ ] 每图一个主要证明任务；
- [ ] 观察、定量关系和局部判断顺序清楚。

### Discussion

- [ ] 每个主要箭头得到解释；
- [ ] 各性能来源分开建立；
- [ ] 替代解释有真实依据；
- [ ] 适用范围明确；
- [ ] 没有新增未支持主线。

### Conclusion

- [ ] 与摘要和正文同序；
- [ ] 无新数据、新机制和新推广；
- [ ] 定量结果和条件完整。
