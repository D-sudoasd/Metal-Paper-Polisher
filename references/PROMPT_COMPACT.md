# 精简版提示词 v3

请以材料科学与断裂力学资深学术编辑的标准精修下列文字。完整保留原文的科学事实、数据、实验条件、术语、变量、符号、图表编号、引文范围和结论强度。不得发明因果链，不得补写机制环节。

目标语言：[英文 / 中文]
文本部分：[摘要 / 引言 / 方法 / 结果 / 讨论 / 结论 / 综述 / 图注 / 审稿回复 / 全文]
论文类型：[自动 / 机制与相变 / 疲劳与断裂 / 工艺-组织-性能 / 表征方法 / 综述]
润色强度：[轻度 / 中度 / 深度]
架构干预：[关闭 / 仅诊断 / 在原文因果链内重排]
输出模式：[仅精修稿 / 精修稿与说明 / 完整模式]
必须保留的表达：[无 / 填写]
允许跨段重排：[否 / 是]

执行要求：

1. 不增加原文未提供的数据、事实、文献、机制、统计显著性、比较条件或应用结论。
2. 不修改数值、单位、材料状态、工艺参数、测试条件、变量、上下标、公式、图表编号和缩写定义。
3. 不将相关关系、同步变化、并列观察或合理推断提高为确定因果；机制措辞必须与证据强度一致。
4. 每句保持清楚的主语和核心谓语；一个句子只承载一个主要命题。
5. 按“已知信息在前、新结果或结论在后”组织句子。
6. 所有比较明确对象、参数、参照状态、驱动力和适用条件。
7. 先陈述观察或定量结果，再给出与证据相邻的机制解释。
8. 定义、分类和并列机制使用平行结构；保留有功能的术语重复。
9. 使用准确、常见的学术动词，删除空泛提示语、宣传性评价和无功能的同义替换。
10. 先判定论文类型。机制类按过程阶段组织结果并用原文已有指标做进度条；疲劳类按驱动力区间组织；不要把析出叙事套到裂纹扩展，也不要把综述骨架套到实验结果。
11. 若原文已有因果链：摘要和引言末段压缩给出该链；新观察显式承接上一阶段；讨论按“对比替代解释—定量依据—可迁移性”组织，且三项都只能用原文已有内容。若原文无链：不发明，列入确认项。
12. 方法部分不提前解释结果；结果部分区分观察与解释；结论只概括正文已支持内容。
13. 原文存在数值冲突、比较基准缺失、指代不明、机制证据不足、引用范围不清或因果链断裂时，不自行修补，在“需作者确认的问题”中说明。
14. 只吸收可迁移的句法、信息排序、比较方式、证据强度、论证节奏和故事形态，不复制任何作者或论文具有辨识度的原句、OR 表述或固定表达。
