# 金属材料论文类型路由（v5）

论文的故事形态由核心科学问题决定。期刊名称、材料牌号、表征手段或标题中的单个关键词不能单独决定类型。

## 1. 判定流程

依次回答：

1. 作者最终希望读者接受的主张是什么？
2. 该主张的因变量是组织过程、变形过程、性能、损伤、环境作用、制造质量、测量能力还是模型预测？
3. 论文中哪一类证据占主导？
4. 摘要的第一项明确未知问题是什么？
5. 结论中最重要的第一条回答了什么？

据此选择一个主类型。其他类型作为次要模块。

## 2. 类型总表

| 代码 | 类型 | 核心问题 | 主线形态 | 典型证据 |
|---|---|---|---|---|
| M | 组织演化、相变、析出、形核与长大 | 过程如何发生 | 初态 → 先导事件 → 中间态 → 终态 → 机制 | 原位/分阶段显微、成分、晶体学、热力学、计算 |
| P | 性能导向设计、多性能协同、性能突破 | 怎样获得目标性能组合 | 需求 → 瓶颈 → 设计 → 组织 → 性能 → 代价被抑制 | 定量性能、对照、组织、变形/损伤证据 |
| D | 变形机制、载荷分配、相/晶粒族响应 | 材料怎样承载和分配变形 | 初始状态 → 屈服顺序 → 载荷转移 → 机制竞争 → 局部化/损伤 | 原位衍射、DIC、EBSD、TEM、晶体塑性 |
| F | 疲劳、裂纹扩展、断裂、损伤容限 | 裂纹怎样萌生、扩展和失稳 | 驱动力/尺度 → 裂纹过程 → 内禀/外禀机制 → 寿命或韧性 | da/dN、ΔK、Kmax、R、断口、裂纹闭合、韧性 |
| E | 氢脆、环境辅助开裂、腐蚀和氧化损伤 | 环境怎样改变损伤阶段 | 环境状态 → 局部改变 → 裂纹/损伤阶段 → 失效 → 条件边界 | 氢含量、陷阱、原位损伤、界面、腐蚀/氧化动力学 |
| T | 蠕变、高温变形、热稳定性 | 高温下的速率控制和组织稳定性 | 温度/应力 → 组织演化 → 控速过程 → 寿命或稳定性 | 蠕变曲线、应力指数、活化能、析出粗化、位错结构 |
| A | 加工、制造、增材、连接 | 工艺怎样决定缺陷和组织 | 工艺窗口 → 热史/凝固/缺陷 → 组织 → 各向异性/性能 → 稳定性 | 工艺参数、熔池、孔隙、织构、残余应力、性能 |
| Q | 表征、测量和定量方法 | 怎样可靠测量某个量 | 能力缺口 → 协议 → 标定/验证 → 不确定度 → 边界 | 标样、误差、分辨率、重复性、交叉验证 |
| C | 计算、模型和预测 | 模型能解释或预测什么 | 问题 → 假设/参数 → 验证 → 解释或预测 → 敏感性与边界 | DFT、MD、相场、CPFEM、有限元、数据驱动 |
| R | 综述、观点和路线图 | 领域证据怎样分类、冲突和演进 | 范围 → 分类/判据 → 证据对比 → 缺口 → 路线 | 系统文献、分类标准、跨体系比较 |

## 3. 各类型的 Results 顺序

### M：组织演化与相变

推荐顺序：

1. 初始相、成分、缺陷和取向基准；
2. 最早可识别的局部变化；
3. 中间态、胚胎或临界结构；
4. 生长、粗化、取向、界面或变体演化；
5. 终态组织；
6. 对关键局部过程的能量、几何或动力学支持。

安全门：不同样品的快照不能自动构成连续动力学。

### P：性能导向设计

推荐顺序：

1. 设计是否产生目标成分、相、缺陷或层级组织；
2. 目标性能是否在明确条件下得到实现；
3. 与对照材料和可比文献的定量位置；
4. 变形、损伤或裂纹过程；
5. 局部机制证据；
6. 必要的定量分解或模型验证。

安全门：性能提高和组织变化同步出现时，组织只能先写为关联；受控对照或定量机制证据决定是否进入因果。

### D：变形与载荷分配

推荐顺序：

1. 初始相分数、织构、残余应力和组织；
2. 宏观应力—应变响应；
3. 相、晶粒族或区域的弹性响应；
4. 首次偏离线性和屈服顺序；
5. 载荷转移、滑移、孪生、相变或晶粒转动；
6. 变形不均匀性和损伤前兆；
7. 变形后局部组织验证。

安全门：衍射峰宽、强度和峰位分别代表不同信息，不能相互替代。

### F：疲劳与断裂

推荐顺序：

1. 材料状态、裂纹类型、几何和加载条件；
2. 裂纹萌生或裂纹扩展曲线；
3. 驱动力区间、裂纹尺度、载荷比或环境效应；
4. 裂纹闭合、屏蔽、塑性区和断口证据；
5. 小裂纹与长裂纹、循环与准静态或不同组织的受控比较；
6. 寿命、门槛值、韧性或损伤容限后果。

安全门：任何速率比较都应明确 ΔK、Kmax、R、裂纹尺寸和环境。

### E：氢脆与环境损伤

推荐顺序：

1. 初始组织和环境/氢状态；
2. 宏观性能退化；
3. 局部变形或化学变化；
4. 裂纹形核位置与时序；
5. 裂纹扩展路径和断口；
6. 氢位置、陷阱、界面或中间过程的独立证据；
7. 去氢、改变应变率、温度或环境的对照。

安全门：断口和延性下降不能单独识别 HELP、HEDE、氢化物或界面脱粘。

### T：蠕变和高温

推荐顺序：

1. 初始组织及热稳定性；
2. 蠕变或高温变形曲线；
3. 应力、温度和时间依赖；
4. 组织、析出物、位错和界面演化；
5. 速率控制过程及转变；
6. 断裂或寿命后果。

安全门：由应力指数和活化能推断机制时应保留模型假设和误差范围。

### A：加工与制造

推荐顺序：

1. 工艺参数和热史；
2. 缺陷、几何和组织形成；
3. 相分数、织构、晶粒和残余应力；
4. 性能和各向异性；
5. 后处理对缺陷和组织的影响；
6. 工艺窗口和可重复性。

安全门：工艺参数通常同时改变多个变量，单一组织因素的因果归属需要额外对照。

### Q：表征与方法

推荐顺序：

1. 现有方法无法可靠测量的具体量；
2. 新协议或算法；
3. 标定和验证；
4. 精度、分辨率、重复性和不确定度；
5. 已知样品或问题中的演示；
6. 适用范围和失效条件。

安全门：方法演示中的新现象仍应保持演示定位，除非论文提供独立机制证据。

### C：计算与模型

推荐顺序：

1. 科学问题和模型对象；
2. 假设、边界、参数与标定；
3. 基准验证；
4. 模型输出和变量依赖；
5. 与实验的对应；
6. 预测、敏感性和边界。

安全门：拟合、解释和预测需要明确区分。

### R：综述

推荐顺序：

1. 范围和纳入标准；
2. 概念定义和分类；
3. 不同材料、尺度或机制的平行比较；
4. 证据一致与冲突；
5. 未解决问题；
6. 可执行研究方向。

安全门：不要把时间顺序文献罗列当作科学分类。

## 4. 混合类型

### 4.1 M + P

判定问题：论文主要贡献是“解释组织如何形成”，还是“通过该组织获得性能”？

- 前者以 M 为主，性能放在后果层；
- 后者以 P 为主，相变或析出机制作为解释层。

### 4.2 D + P

- 主张为“Cu 改变相间载荷分配机制”：D 为主；
- 主张为“通过 Cu 获得更高强塑性，载荷分配用于解释”：P 为主。

### 4.3 E + P

- 主张为“氢如何改变裂纹形核机制”：E 为主；
- 主张为“某设计提高抗氢脆性能”：P 为主，E 为损伤证据模块。

### 4.4 A + P

- 主张为“工艺窗口和缺陷形成”：A 为主；
- 主张为“通过制造路线获得性能”：P 为主，A 为设计动作。

### 4.5 C 与其他类型

计算通常作为次要模块。只有模型本身的预测能力、方法或新理论为主要贡献时，C 才作为主类型。

## 5. 类型误判检查

- 标题出现 mechanism，不代表 M；全文若围绕性能突破展开，应判为 P。
- 论文包含 DFT，不代表 C；DFT 可能只是 M、P 或 E 的证据。
- 论文包含拉伸曲线，不代表 P；若主问题是相间载荷转移，应判为 D。
- 论文包含断口，不代表 F 或 E；断口可能只是性能论文的失效证据。
- 论文包含同步辐射，不代表 Q；若手段用于揭示变形过程，应判为 D。
- 论文包含氢，不代表 E；若目标是开发抗氢材料，主类型可能为 P。

## 6. 路由输出

完整模式下报告：

- 主类型；
- 次要模块；
- 判定依据；
- 主线；
- 不适用的叙事模板；
- 当前文本中类型混杂的位置。
