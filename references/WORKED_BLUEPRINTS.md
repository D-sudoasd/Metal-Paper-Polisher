# 结构示例与研究蓝图（v4）

本文件只示范逻辑层级和段落功能。方括号中的内容必须由作者数据填写。示例中的可能机制不能自动写入论文。

## 1. 组织转变/形核长大机理论文

### 一句话问题

> 在【初始相/组织】中，【目标相或缺陷】如何从【先导事件】形成并演化为【终态】？

### Results

1. **初始状态**：相组成、溶质、缺陷、取向和定量零点；
2. **最早变化**：团簇、偏聚、局部应变或界面变化；
3. **中间态**：胚胎、临界结构或过渡相；
4. **长大**：尺寸、界面、取向和变体；
5. **终态**：最终组织；
6. **局部原因**：结合能、点阵对应或动力学数据。

### Discussion

1. 先导事件为什么发生；
2. 先导事件如何改变局部成分、结构或势垒；
3. 该变化怎样形成目标相；
4. 长大为何改变界面或取向；
5. 其他路径为什么不足；
6. 机制在哪些条件下可迁移。

## 2. 性能设计论文

### 一句话问题

> 【设计动作】如何改变【中间物理过程】，同时提高【性能 P1】并保留或提高【性能 P2】？

### Results

1. 目标组织是否形成；
2. P1、P2 的数值、条件和对照；
3. 性能形成的变形/损伤阶段；
4. P1 对应的局部机制证据；
5. P2 对应的局部机制证据；
6. 必要的模型或定量贡献。

### Discussion

1. P1 的来源；
2. P2 的来源；
3. 通常性能代价为何受到抑制；
4. 多个组织变量的贡献能否分离；
5. 文献基准是否可比；
6. 必要条件和推广边界。

## 3. 含 Cu TC4 的同步辐射变形研究

本示例适用于“Cu 改变 TC4 中 α/β 相变形分配”的研究。所有具体机制和相名称需由实际证据确认。

### 3.1 核心问题

> Cu 通过改变哪一组织或相级中间变量，重新组织了 α 相与 β 相的屈服顺序、载荷分配和局部变形，从而影响宏观加工硬化和失效？

### 3.2 可能的主线分支

根据数据选择一条：

```text
Cu 状态/含 Cu 相/相分数变化
→ α/β 强度差变化
→ 屈服顺序和载荷转移变化
→ 相级应变分配与局部化变化
→ 加工硬化和损伤变化
```

缺少 Cu 状态或局部机制证据时，第一箭头保持关联。

### 3.3 Results 顺序

#### R1 初始状态

回答：Cu 以什么状态存在，两组材料是否可比？

报告：

- 成分和 Cu 分布；
- 是否存在含 Cu 相；
- α/β 相分数；
- 片层/晶粒尺寸；
- 织构；
- 残余应力；
- 初始同步辐射谱。

局部结论：明确可比变量和同步变化的混杂变量。

#### R2 宏观响应

报告：

- 应力—应变；
- 屈服；
- 加工硬化率；
- 均匀延伸；
- 重复性。

只回答性能差异，不立即归因于 Cu 或析出物。

#### R3 相级和晶粒族晶格应变

按加载阶段组织：

1. 共同弹性；
2. 第一相/晶粒族偏离线性；
3. 另一相斜率变化；
4. 两相共同塑性；
5. 损伤前阶段。

局部判断示例：

> 在 α 相晶格应变偏离线性后，β 相晶格应变增长速率升高，表明在该应变区间发生相间载荷重新分配。

该句成立需同一加载序列和明确相级响应。

#### R4 峰宽、峰强、相分数和织构

分别回答：

- 缺陷相关微应变是否增加；
- 晶粒是否转动；
- 是否发生相变；
- 哪些晶粒族承担更高载荷。

不得把峰宽直接写成位错密度，把单峰强度变化直接写成相变。

#### R5 变形后局部证据

使用 EBSD/TEM/DIC 等验证：

- 滑移系；
- 位错结构；
- α/β 界面塞积或传递；
- 含 Cu 相与位错作用；
- 裂纹或孔洞位置。

### 3.4 Discussion 顺序

#### D1 重建变形序列

```text
弹性承载
→ 首先屈服的相/晶粒族
→ 载荷转移
→ 两相共同塑性
→ 局部化
→ 损伤
```

#### D2 确定 Cu 作用环节

根据证据判断：

- Cu 固溶；
- 含 Cu 析出相；
- 相分数；
- 织构；
- 片层尺度；
- 界面结构。

只有直接证据足够时指定具体机制。

#### D3 连接加工硬化

可检验链：

```text
两相强度差
→ 载荷转移
→ 相间应变不协调
→ 位错储存/背应力或局部化
→ 加工硬化
```

没有背应力或局部证据时，写为 consistent with increased phase-level strain partitioning。

#### D4 替代解释和边界

检查相分数、织构、残余应力、弹性常数、表面状态和试样方向。

## 4. 氢脆研究

### 4.1 核心问题

> 氢主要改变损伤过程的哪一阶段，并通过哪些直接可测的中间过程导致性能退化？

### 4.2 主线

```text
氢进入与陷获
→ 局部塑性/界面/相稳定性变化
→ 应变集中位置和时间变化
→ 裂纹形核变化
→ 裂纹扩展变化
→ 宏观性能退化
```

每个箭头独立核查。缺少氢位置或中间过程时降低机制强度。

### 4.3 Results 顺序

#### R1 氢和初始组织

- 总氢、可扩散氢、陷阱；
- 充氢、等待时间、温度和应变率；
- 相组成和残余应力；
- 表面层和氢梯度。

#### R2 宏观效应

- 强度、延性、韧性、疲劳或裂纹速率；
- 未充氢对照；
- 氢含量和应变率依赖。

#### R3 局部变形

- 局部应变何时出现；
- 滑移是否更集中；
- 相界、晶界或夹杂附近是否优先；
- 未充氢对照是否存在同样行为。

#### R4 裂纹形核

- 首裂纹应变；
- 位置；
- 与局部应变、滑移、界面、氢化物的时间和空间关系。

#### R5 裂纹扩展和断口

- 路径；
- 穿晶/沿界；
- 裂尖塑性；
- 形貌；
- 速度或阶段。

#### R6 独立机制证据

- 氢/氘位置；
- TDS；
- APT/SIMS/中子；
- TEM 位错；
- 氢化物；
- 界面/扩散计算；
- 去氢或陷阱对照。

### 4.4 Discussion 顺序

1. 确定氢主要影响的损伤阶段；
2. 连接局部变形和裂纹时序；
3. 评价 HELP、HEDE、氢化物或陷阱机制所需证据；
4. 解释组织因素怎样改变局部氢和应力；
5. 处理应变率、温度、三轴度和氢梯度；
6. 给出受限结论。

### 4.5 受限措辞示例

```text
The spatial and temporal correspondence between interfacial strain localization and crack initiation indicates that hydrogen-assisted damage begins with intensified deformation incompatibility at the interface.
```

进一步指定 HELP 或 HEDE 需独立证据。
